Dynamic capture in MAPLIST and DIFF

hyperdoc

Goal

Make the evaluator's dynamic environment visible with the smallest executable witness, then relate that mechanism conservatively to the MAPLIST/DIFF collision discussed by Graham.

Starting situation

((lambda (x)
   ((lambda (f)
      ((lambda (x)
         (f 'ignored))
       'inner))
    '(lambda (z) x)))
 'outer)

A lexical closure would retain the outer binding of X. The historical evaluator carries only the active association-list environment into the call, so the inner binding is visible when F runs.

Step 1 — run the witness

Click: run the dynamic-capture example. Observe: the returned ROOTS-EVALUATION has status :OK and value INNER. Why this matters: the value is direct evidence of dynamic capture, not a claim inferred only from the evaluator's source text.

Step 2 — inspect the binding trace

Click: inspect the evaluation's event list and open its :LAMBDA-BIND events. Observe: the newest X binding is INNER when the quoted function expression is applied. Why this matters: the evaluator does not carry the function's definition environment as a closure or FUNARG.

Expected result

Historical dynamic environmentINNER
Lexical expectationOUTER

Boundary

Graham's local repair is to rename the colliding MAPLIST parameter. The semantic repair would instead carry a function's definition environment as a closure/FUNARG. This reconstruction deliberately makes neither semantic change. It provides a source-backed explanation of the MAPLIST/DIFF collision plus an executable minimal witness; it does not claim a full replay of those historical definitions without a separately verified primary-source transcription.
