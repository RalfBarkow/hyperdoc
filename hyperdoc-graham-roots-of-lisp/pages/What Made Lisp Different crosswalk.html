The decisive cluster

Ideas 6–9 converge in this source station: programs are expressions; symbols are data; code is represented as trees of those symbols; and the reader, evaluator, definitions, and inspection operations coexist in the running image. The evaluator therefore becomes both program and readable object.

A historical qualification

The evaluator reconstructed here uses an explicit dynamic environment. It should not be silently read as a model of modern Common Lisp lexical closures. The HyperDoc page should preserve that difference because it is part of understanding what the 1960 construction did and did not establish.
