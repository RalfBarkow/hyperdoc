HyperDoc Server

hyperdoc/server

To start a Web server serving HyperDocs, use one of 

  • serve-catalog
     
  • serve-hyperdocs

In both cases, the server will serve all registered HyperDocs from URLs computed from their titles by the function 

slug
. 
serve-catalog
 will serve a catalog of all registered HyperDocs at the root URL of the server, whereas 
serve-hyperdocs
 will serve an inspector on another object of your choosing. This is typically a HyperDoc with an introduction to the topics covered by the server, but it can be any Lisp object.

You must load the HyperDocs you want to serve before starting a server. This requires no more than loading the systems containing them via standard ASDF operations.
