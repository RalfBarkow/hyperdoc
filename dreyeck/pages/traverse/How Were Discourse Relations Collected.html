How Were Discourse Relations Collected?

Two mechanisms read the same fold structure. The survey runs from time to time and stores its result in a Wiki page. EXTRACT reads the pages afresh each time its Mech block runs.

The survey: probe, store, read back

Claim Link Survey Probe (retained) holds a frame that launches the Site Survey Factory with probe=ClaimLinkSurveyProbe. A code item describes the record it produces for each page: folds, links by fold, and edges.

The probe is a JavaScript module served by discourse.dreyeck.ch as an asset, not taken from Git:

  • analysePage walks the story and starts a new fold at each pagefold;
  • normalizeFoldName also accepts objection;
  • extractLinksFromItem reads paragraph, markdown, html and reference items.

Only a link inside a recognized fold becomes an edge, and an edge names slugs, not sites. The survey's update applies the probe to the site's pages and opens a new page with the result, which an author then saves.

Claim Link Survey is that saved page, created on 2026-01-21. Its frame item carries the survey array: 107 pages and 87 edges. In the Mech program, NEIGHBORS reads this array when the line Claim Link Survey is indented under it, and neighbors_emit merges each page's record into its sitemap entry.

EXTRACT: direct, at run time

extract_emit fetches every page of the neighborhood when it runs. extract_edges_from_story then turns each link in a paragraph or reference item under a recognized fold into an edge from page to site+slug. Three helpers do the details:

  • normalize_fold and canonicalize_fold name the role;
  • Ward's asSlug makes the slug.

The edge records the page, the fold and the target. It does not record the story item; this reading finds that item again for each edge.

The same snapshot, three counts

Compare the counts:

  • Stored survey, 2026-01-21: 87 edges on 107 pages.
  • Probe, applied to the retained snapshot: 91 edges on 110 pages.
  • EXTRACT, on the same snapshot: 86 edges.

Between the probe and EXTRACT, two rules explain every difference:

  • Five probe edges come from markdown items, which EXTRACT does not read.
  • Eight edges point at titles with a dash between spaces. asSlug turns "Popitz – Power Forms" into popitz--power-forms, while the probe collapses it to popitz-power-forms.

The stored survey is older than the snapshot, so it differs from both for a third reason as well: the pages changed in between.
