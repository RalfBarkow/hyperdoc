Two endpoints, two readings

A D2 connection relates shape keys. In source -> target, source is the starting endpoint and target carries the arrowhead. source -- target draws an undirected connection. Arrow direction expresses a diagram relation; it is not a command to change either endpoint. The keys identify shapes in this diagram, not global HyperDoc Topics.

Our original minimal example uses the same two shapes for a directed dependency and an undirected comparison. D2 keeps these as two connections. Source: official D2 Tour: Connections. This is a locally authored example, not a gallery copy.

Compare with HyperDoc

A HyperDoc Topicmap Association has an ID, type and Topic-ID endpoints. A D2 connection has diagram-local endpoints and graphical direction. An Association can be projected as D2, but the authored edge above is not itself an Association. TALA chooses placement and routing; it does not choose HyperDoc semantics.

Related concepts in the native work Topicmap: D2, Connection, Association, Connect and Topicmap. The example's Topic refers to this page; the runtime render remains inspectable through the executable example.
