Counterexample: one edge belongs to two trails

The explicitly synthetic inputs A → B → C and X → B → C share B → C. Solo returns four nodes and three relations. The shared edge records only synthetic A as source. Reversing input order makes synthetic B win. More strongly, removing B → C from the second input produces the identical entire complex: no algorithm given only that result can distinguish the two memberships from one. The loss occurs in merge's matched-relation branch: mergeprops keeps the first truthy property and adds no second membership.

Composition also mutates input relation properties when assigning source. Graph.addNode and addRel create new node/relation objects but reuse their props objects. Later mergeprops additions can therefore affect earlier inputs. These alias checks run on disposable clones; retained input captures remain unchanged.

Graph identity and display identity

dotify uses composite array indices as DOT identifiers. Graphviz emits those identifiers as SVG g.node/title text; its node1-style element IDs are render-generated. The test matches every input node via its composite ID to the actual SVG group. It also checks every directed edge and its Trail label. Real wheel zoom changes the viewport transform while preserving these identifiers in the tested DOM. Coordinates and transforms are not graph identities.

This proves an identifier correspondence for this execution, not stable SVG IDs under arbitrary re-layout, resizing, reload or renaming. It does not recover original trail membership. The original public captures remain historical observations; these new offline runs are separately identified.

Smallest requirement for trails[]

Before relation deduplication, retain each selected trail's identity within the selection and its ordered occurrences of local nodes/relations, mapped to composite identifiers. Multiple trails must be allowed to refer to the same composite edge. Use an aspect identity qualified by its source/selection, not only a display name. This is a derived requirement for Ward's proposal, not an implementation. No Polyline, new merge semantics or renderer metadata has been added.
