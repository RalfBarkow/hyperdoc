Compare every file before selection, including index.html, host.js, wiki-dialog.js, neighborhood.js and plugins/mech modules. HTTP 200 can be a generic Wiki page: require byte equality and appropriate JavaScript MIME types. Record CSP, framing and cache headers; an absent CSP is not the local launcher's tested CSP. A receiver mismatch requires investigation, not overwriting the root Wiki receiver.

# Continue in the same Bash session. This function checks every shipped file.
verify_host() {
  local base=$1 resource mime
  while IFS= read -r -d '' resource; do
    resource=${resource#"$version_dir/"}
    curl --fail --silent --show-error -H 'Cache-Control: no-cache' \
      -D "$receipt/headers" "$base/$resource" -o "$receipt/body" || return 1
    cmp "$version_dir/$resource" "$receipt/body" || return 1
    mime=$(sed -n 's/^[Cc]ontent-[Tt]ype: *//p' "$receipt/headers" | tr -d '\r')
    case "$resource" in
      *.js) [[ "$mime" == application/javascript* || "$mime" == text/javascript* ]] || return 1 ;;
      *.html) [[ "$mime" == text/html* ]] || return 1 ;;
      *.css) [[ "$mime" == text/css* ]] || return 1 ;;
    esac
  done < <(find "$version_dir" -type f -print0)
  curl --fail --silent --show-error "$base/" -o "$receipt/directory-body" || return 1
  cmp "$version_dir/index.html" "$receipt/directory-body"
}
verify_host "https://mech.dreyeck.ch/assets/hyperdoc-mech-versions/$MECH_REV"
# Distinct existing root receivers, not copies installed at new root routes.
curl -fsS -D "$receipt/popup-headers" https://mech.dreyeck.ch/dialog/ -o "$receipt/popup"
cmp "$version_dir/dialog/index.html" "$receipt/popup"
curl -fsS -D "$receipt/solo-headers" https://mech.dreyeck.ch/plugins/solo/dialog/ -o "$receipt/solo"
cmp "$version_dir/plugins/solo/dialog/index.html" "$receipt/solo"

After selection, inspect a fresh browser's Network responses (disable cache) and compare actual loaded module bodies to the selected copy. Keep the observed URLs, headers, digests and time. A cached open frame can retain old modules after a symlink switch. Open Trails Rendered through the native Inspector: display alone executes no Code; first CLICK returns two aspects; SOLO transfers both and composes five nodes/four Trail relations. Check documentation navigation, visible import failures and the unchanged Preview error. For POPUP, verify the second Pattern Machinery CLICK shows the calculated state and reuses the regular dialog; do not prescribe counts without the same sitemap input.

Mech runs in the browser, separate from the HyperDoc Inspector but sharing the Wiki origin and potentially its privileges. The original /dialog/ receiver for POPUP validates neither event.origin nor event.source. Original POPUP state escapes values, not all keys. SOLO uses the different /plugins/solo/dialog/ receiver. The observed missing CSP is a boundary, not silently supplied protection. A public demonstration does not establish safe general execution of arbitrary Wiki programs.
