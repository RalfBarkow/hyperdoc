Select, verify, then activate

Catalog procedure and rollback: normally retain the configured branch, update its lock and review the resulting OID before building. Explicit commit pinning changes the input declaration and its future tracking policy. Activation requires separate approval.

Mech asset procedure and rollback: install a missing version; verify an existing version without overwriting it. Refuse differences. Compare versioned HTTP responses before approving the symlink switch; an already selected verified version needs no change.
