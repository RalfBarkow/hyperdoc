wiki.ralfbarkow.ch deployment

What was running on wiki.ralfbarkow.ch, and what would changing its Wiki package mean?

Federated Wiki has a server that delivers pages and accepts authorized page actions, a client that runs in the browser, and plugins that provide item types and operations. On this host, systemd's wiki.service keeps the server process running and selects which executable starts it.

Nix constructs a package from chosen source revisions and dependencies. The package contains the executable and its client/plugin assets. A source branch describes choices; a package is the result of a build; activation selects the package a service starts. These are three different identities.

The historical P41 witness

The operator reported a P41 Wiki package and wiki.service active and running, with startup pointing to that package's bin/wiki. The witness also names the corresponding source revision. Its capture time was not supplied, so this describes the reported deployment, not a fresh observation of today's host.

A newer configuration offers a choice

The published wiki.ralfbarkow.ch consumer now adds wiki-upstream and wiki-discourse as explicit package outputs. Both retain the existing P41 base recipe and previous default. The first uses upstream Mech; the second composes the independently owned Discourse operations. This is a newer package configuration, not evidence of a production update.
