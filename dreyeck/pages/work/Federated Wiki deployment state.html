What does a deployment observation establish?

A source revision describes code. A Nix package is a built result. A service observation records which process or executable a host was running at a particular time. Linking these identities requires evidence; a newer published branch does not by itself update a service.

Start with the application you want to understand: The reported Wiki package and service on wiki.ralfbarkow.ch or HyperDoc on dreyeck.ch and the separate Wiki farm. Each explanation opens contextual Inspector objects before offering the full records.

The historical snapshots, later confirmation, activation output and time-stamped host observation are preserved separately. Source-based inference remains labeled as inference. Unknown capture time is not replaced by a guessed date, and the Wiki consumer commits are declarations rather than newly observed host packages.
