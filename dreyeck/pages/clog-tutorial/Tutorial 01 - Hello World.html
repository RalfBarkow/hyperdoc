Tutorial 01 — Hello World

One window handler creates a heading and registers a callback that closes over that same object. Clicking the heading calls the callback and changes its browser color to green. A second click changes no object identity and leaves the heading green.

Click → color is the mechanism overview. Tutorial 01 – Live is the running upstream tutorial. Dispatch execution #1 is evidence of one concrete click: which operation targeted which original object, and what result was observed.

Observe a development window

In a development server, run the observation example below before opening a new live window. It retains the original callback at SET-ON-CLICK and the original CLOG dispatcher at SET-EVENT. A forwarding observer becomes the registered event-table entry; it calls the original dispatcher once, with the original data, and records color before and after. Only during that retained Tutorial 01 dispatcher call does it record COLOR writes to the original heading. Neither original closure is rewritten. Showing this page performs none of these steps.

Retention is scoped to this original handler's execution through CLOG's existing debug hook. Registrations elsewhere, even on the same connection, are not captured. The development workflow describes releasing observations.

The Dispatch execution view separates registration context from observed execution: dispatcher entry, requested COLOR write, normal return or non-local exit, and the resulting CSS query. Callback involvement is shown through the retained registration and dispatcher source; no callback-entry boundary or per-click event-table lookup is recorded. Dispatch numbers do not claim browser event receive order.
