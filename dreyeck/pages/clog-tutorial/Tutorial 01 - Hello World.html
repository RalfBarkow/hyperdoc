Tutorial 01 — Hello World

CLOG's first tutorial is one window handler. It titles the page "Tutorial 01", adds the heading "Hello World! (click me!)" and turns it green when it is clicked. Here it runs on the CLOG server this HyperDoc image already serves from, as one more route:

(route-relation (tutorial-1-route))

Each line is read when this page is shown. The handler is the one CLOG's table holds at the route, and its source is the file the image says it was defined from. The live page's address is completed by your browser from the address of this page, so it always points at the server you are reading from. It opens in a tab of its own, as every URL view in this Catalog does: the tutorial is a separate CLOG window with its own connection, not a view of an object.

The handler

This is ON-NEW-WINDOW as the installed CLOG ships it, read from its installation rather than copied:

clog-tut-1::on-new-window

Mounting it in a development server

This is the part of (clog:run-tutorial 1) that applies in HyperDoc; Running the CLOG Tutorials in HyperDoc says which parts do not. In a development server, ► mounts the route and opens it in the Inspector, where its Live page is then a link. A served Catalog does not run it, and the marker in place of ► says why.

mount-tutorial-01

Why the tutorial does not start itself

Upstream, the tutorial owns its server: START-TUTORIAL calls CLOG:INITIALIZE and then opens a browser on the machine running Lisp. CLOG has one server per image, and initializing it again would make the tutorial the handler of / and switch off the extended routing that HyperBook page addresses depend on. INSTALL-TUTORIAL-1-ROUTE therefore loads only the definitions and adds this one path to the server that is running, the way CLOG's Tutorial 12 adds pages. Without a running server it refuses.

What is checked, and what only a browser shows

The tests read CLOG's own tables: the route above holds this handler, its boot page is CLOG's default one, mounting twice changes nothing, and nothing calls CLOG:INITIALIZE. Whether the heading turns green is a fact about a browser connected to a running server, and the live page is where it can be seen.
