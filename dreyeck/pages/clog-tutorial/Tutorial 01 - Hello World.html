Tutorial 01 — Hello World

One window handler creates a heading and registers a callback that closes over that same object. Clicking the heading calls the callback and changes its browser color to green. A second click changes no object identity and leaves the heading green.

Click → color

Read the mechanism through the retained original objects and the observed dispatch. Their links open the existing Inspector views: the heading's Tree and HTML, the callback and dispatcher's Source code, and the event table's Items. The observation shows what the click changed.

The installed source

ON-NEW-WINDOW creates HELLO-ELEMENT with CREATE-CHILD, passes the callback to SET-ON-CLICK, and changes COLOR inside that callback. Read the installed forms here:

clog-tut-1::on-new-window

Observe a development window

In a development server, run the observation example below before opening a new live window. It retains the original callback at SET-ON-CLICK and the original CLOG dispatcher at SET-EVENT. A forwarding observer becomes the registered event-table entry; it calls the original dispatcher once, with the original data, and records color before and after. Neither original closure is rewritten. Showing this page performs none of these steps.

Retention is scoped to this original handler's execution through CLOG's existing debug hook. Registrations elsewhere, even on the same connection, are not captured. The development workflow describes releasing observations.
