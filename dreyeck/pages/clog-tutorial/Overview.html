CLOG Tutorial

CLOG ships a numbered collection of tutorials with its source. Where they come from:

  • the upstream collection, developed in the tutorial directory of the CLOG repository, whose README lists the tutorials' subjects. It may have moved on since the copy installed here;
  • the installed source this server runs: CLOG (asdf:component-version (asdf:find-system "clog")), installed at (namestring (clog:clog-install-dir)). Each tutorial page names its file there and links its handler's source, as this runtime has it;
  • this book, which connects explanation and installed source to retained runtime objects and their observed changes in the Inspector. Existing live routes provide the browser effect surface in a development server.

Four things are kept apart:

  • the collection, which is this book;
  • a tutorial, one item of the collection, read from CLOG's own source;
  • a route such as /clog-tutorial/01, the path at which a tutorial's handler is mounted on this server, which exists only once it is mounted;
  • a window, one browser window that opens a route: CLOG runs the handler once for each, so each has its own elements and state. Tutorial 02 is where this becomes visible.

CLOG's README runs a tutorial with (clog:run-tutorial N), which starts a server of its own. Running the CLOG Tutorials in HyperDoc says what takes its place here, and why it must not be evaluated in this server.

Tutorials in this book

  • Tutorial 01 — Hello World: one window handler, its captured heading and the Click → color mechanism. Its existing execution transport is /clog-tutorial/01. On this server the route is now (route-state (tutorial-1-route)).
  • Tutorial 02 — Closures in CLOG: the Counter → output mechanism, whose clicks accumulate output independently per window. Its existing transport is /clog-tutorial/02. On this server the route is now (route-state (tutorial-2-route)).

The other tutorials in CLOG's directory are not in this book. Each is to be read and classified before it gets a page: where its source and entry point are, whether it initializes CLOG itself, whether its handler can be loaded on its own, which assets it needs, and whether it can be mounted on this server. Tutorials 01 and 02 were classified this way and are mounted by the same steps; that is not assumed of the others.
