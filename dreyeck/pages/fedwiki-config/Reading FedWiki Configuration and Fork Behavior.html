Reading FedWiki Configuration and Fork Behavior

A Federated Wiki installation brings together a process that serves pages, a client that runs in the reader's browser, and plugins that add item types and operations. A configuration describes how to construct that combination. A built package contains its selected assets. A running installation requires a separate activation and observation.

The Wiki server accepts and stores page actions and applies its security provider. The Wiki client manages the lineup, retrieves neighboring pages and initiates browser actions. Mech interprets actions; Code supplies authored JavaScript; Solo receives graph batches for display. Sharing a Mech source does not make two clients, servers or security policies identical.

Inspect the concrete configurations and their retained evidence. These objects lead to exact recipe files, locked client revisions, package component inventories and isolated browser observations. Opening them does not query a host or execute Wiki JavaScript.
