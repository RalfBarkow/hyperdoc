Pull Request Review

The observed pull requests connect proposed changes to source reports and open review questions. Inspect a PR to follow its exact head/base commits, source documents, related Issue objects and external GitHub pages. The Topicmap uses the existing renderer-independent model. Its source-use relationships are not Git merge dependencies.

Warrants and separate human notes retain observed, derived, inferred and hypothesized distinctions. Unsupported, stale or conjectural relationships are not projected as factual edges. A reported PASS is not a human Acceptance Record and changes no Work status.

This local Reading never refreshes GitHub or imports files while rendering. An operator prepares the snapshot explicitly before inspection. The snapshot's observation time and digest qualify all rows; a recent observation does not prove the remote revision is still current. Import a new observation explicitly to compare revisions. An unavailable observation is distinct from zero open PRs.

This book is unregistered by default. Production Catalog admission, any HTTP route and service deployment are separate proposals. No GitHub write, merge, project Work mutation, MCP action or new ISO Topic Maps representation is offered.
