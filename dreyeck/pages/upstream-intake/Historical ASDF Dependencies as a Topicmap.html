Keep the four layers separate

  • The fachliche objects are a historical Git commit, its file, ASDF system declarations, dependency references, and the current-image resolution observations.
  • HISTORICAL-ASDF-REFERENCE-TOPICMAP projects those objects onto the general Dreyeck Topicmap contract: topics, typed associations, temporal scopes, and view properties. DMX is the model reference for these concepts, not a runtime dependency.
  • The generic Dreyeck Inspector view is named Topicmap. Any inspectable object can participate by supplying the same renderer-independent projection. HyperDoc provides its Inspector and Lineup as an unchanged library.
  • The current Dreyeck renderer presents the projection as native CLOG/SVG and keeps its topics inspectable. DM6/Elm is neither a core dependency nor part of this implementation slice.

Historical extraction never reads, loads, or evaluates the committed ASD file. Simple string and symbol designators are canonicalized structurally; unsupported forms remain inspectable evidence. Current resolution is a separate observation against ASDF:REGISTERED-SYSTEM, so an unresolved dependency does not trigger discovery, loading, Quicklisp, or a network operation.

Reproduce the path from SLY

(asdf:load-system "dreyeck/inspector/git")
(defparameter *historical-dreyeck-commit*
  (dreyeck/git:make-git-commit
   :repository (dreyeck/git:current-git-repository-checkout)
   :commit-ish "e3f69fcf37cca51f32bd55bcf372134e2cdb77a7"))
(defparameter *historical-dreyeck-asd*
  (dreyeck/git:make-git-file-at-commit
   :commit *historical-dreyeck-commit*
   :path "dreyeck.asd"))
(clog-moldable-inspector:clog-inspect :object *historical-dreyeck-asd*)
