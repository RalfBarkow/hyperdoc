Observing an Upstream Commit

dreyeck/upstream-intake

What does it mean for an upstream commit to be present locally? This case starts with 4a0a9d859148e23b6f1ec8ec106145aa68c79c7c from khinsen/hyperdoc, whose subject is Catch and handle "host not found" error for fedwiki sites. The reference is observed against the checkout and Lisp image current when the named example runs.

Named executable example

HYPERDOC-HOST-NOT-FOUND-UPSTREAM-INTAKE-EXAMPLE observes the upstream commit without integrating it. The returned object opens directly in its Upstream Intake view.

Run the named host-not-found example and inspect the current result

What to notice

  • whether the commit object is present locally;
  • whether it is an ancestor of the current HEAD;
  • its current merge base and refs containing it;
  • the current classification, which is observation data rather than a title;
  • the actual changed file: hyperbook-fedwiki/fedwiki.lisp;
  • the changed definition: HYPERBOOK/FEDWIKI::MAKE-FEDWIKI;
  • whether that function is already fbound in the current Lisp image;
  • a separately labelled potential live function redefinition.

Interpretation

Object presence is not integration. A live function overlap is not proof that loading the commit is safe. The current branch has subsequently refactored FedWiki initialization, so commit identity, patch equivalence, current behavior, and an integration decision remain separate questions.

Historical evidence, not a permanent assertion

At local commit f840514, the read-only observation was: 

:OBJECT-PRESENT-P     T
:ANCESTOR-OF-HEAD-P   NIL
:MERGE-BASE           954cf797c1651959aaad249db80e7c73218584e9
:CLASSIFICATION       :AVAILABLE-NOT-INTEGRATED

These values are historical evidence. The executable example reads the current repository state. If the upstream commit later becomes an ancestor of HEAD, the classification may become :ALREADY-INTEGRATED. Such a change is a new observation, not a documentation or test failure.

No removed or renamed definition is evidenced by this patch, so this observation does not assert a stale-live-definition consequence.

Implementation and provenance on demand

The factory source answers “How is this observation constructed?” Following the inspectable upstream commit supplies Commit, Metadata, Stat, Changed files, and Patch views.
