From a FedWiki page to an inspectable HyperDoc

dreyeck/fedwiki-hyperdoc

This page follows one local Federated Wiki page through the production boundaries that turn a page-attached ASDF definition into an inspectable Runtime HyperDoc. 

FedWiki page
  -> read-only asset discovery
  -> trusted page-attached ASD
  -> registered ASDF systems
  -> HyperDoc presentation system
  -> HyperDoc activation
  -> Runtime HyperDoc

Prerequisite

The executable examples use the local site ~/.wiki/wiki.ralfbarkow.ch/ and the FedWiki slug reading-java-source-as-data.

1. Observe the page-attached ASDF relation

Discovery is read-only. It observes the relation between the local FedWiki page and its page-attached asset bundle without evaluating the ASD file.

Inspect the read-only page-attached ASDF discovery observation

2. Cross the trust boundary

A discovered ASD is executable Lisp. Before it is evaluated, the production operation verifies that its truename remains below the local site's assets directory.

Inspect the trusted ASD and its containment evidence

3. Register and inspect the systems defined by the ASD

Registration is the first effectful boundary. The observation retains the systems visible before and after evaluating the page-attached ASD.

Register the page-attached ASD and inspect before/after evidence

4. Select the HyperDoc presentation system structurally

The presentation system is not selected by a naming convention. A candidate must have a plain direct ASDF dependency on hyperdoc.

Inspect the ASDF systems and their HyperDoc presentation candidate

5. Load the presentation system and observe HyperDoc registration

Loading the selected presentation system is effectful. The activation observation distinguishes HyperDocs present before loading from the catalog state afterwards.

Load the presentation system and inspect its HyperDoc activation

Repeating this example in the same Lisp image may produce no :NEWLY-REGISTERED-HYPERDOCS, because the HyperDoc can already be present. The before/after observation deliberately exposes that live-image state rather than hiding it.

6. Run the production operation end to end

The individual observations above are composed by the production operation ACTIVATE-LOCAL-FEDWIKI-PAGE-HYPERDOC.

Inspect the source of ACTIVATE-LOCAL-FEDWIKI-PAGE-HYPERDOC

activate-local-fedwiki-page-hyperdoc

Inspect the complete FedWiki-to-HyperDoc activation result

7. Inspect the Runtime HyperDoc itself

The end-to-end result retains the Runtime HyperDoc as an object rather than reducing the operation to a success flag.

Open the Runtime HyperDoc in the Moldable Inspector

What this demonstrates

Discovery, trust, ASDF registration, presentation selection, HyperDoc activation, and Runtime HyperDoc inspection are distinct relations. The end-to-end production operation composes them while retaining evidence from every stage.
