Editing One Isolated Wiki Page

dreyeck/fedwiki-original-editor-demo

This demonstration reads a disposable local Wiki page. Only the original Wiki server writes it. Open the original client, enable editing, double-click the code, change its text and language, then click outside the item to save. Return here and choose Read stored page again. A new observation reads the JSON file.

This HTML paragraph carries an explicit reference to the Wiki paragraph item. It contains an explanation of the reference, not a second editable copy of that item's text. The attributes are inspectable in the HyperDoc parse tree; they add no automatic conversion.

For the item-specific embedded editor, click the small code Inspector reference, select Original Wiki editor, then activate Edit with original Wiki plugin. Only the selected Code Item is exposed in that frame. After saving, Read stored page again independently verifies the file. No second browser tab is needed for this path.

The paragraph item is selectable too: in the page's Story view below, click the small paragraph reference, select Original Wiki editor and edit it with the original text editor.

The client link opens the page. This demonstration supplies no navigation to an individual item. The two-item page makes the code item immediately visible.

Every Catalog contains this HyperBook; only the isolated test launcher configures it. Without that configuration, as in a public Catalog, the part below says what is not configured and offers no editor. Showing the HyperBook grants no write permission: writes are authorized, or refused, by the original Wiki server alone.
