Editing One Isolated Wiki Page

dreyeck/fedwiki-original-editor-demo

This demonstration reads a disposable local Wiki page. Only the original Wiki server writes it. Open the original client, enable editing, double-click the code, change its text and language, then click outside the item to save. Return here and choose Read stored page again. A new observation reads the JSON file.

This HTML paragraph carries an explicit reference to the Wiki paragraph item. It contains an explanation of the reference, not a second editable copy of that item's text. The attributes are inspectable in the HyperDoc parse tree; they add no automatic conversion.

The client link opens the page. This demonstration supplies no navigation to an individual item. The two-item page makes the code item immediately visible.
