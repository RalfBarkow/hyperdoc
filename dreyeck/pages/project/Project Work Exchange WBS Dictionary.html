Project Work Exchange WBS Dictionary

Draft. This page is not a source of the project CTM. It proposes what the WBS Dictionary of the proposed Deliverable project-work-ctm-exchange would state, in the form of the CTM Plan Page WBS Dictionary: for each work package its scope, acceptance criterion, authority, effect, the evidence it requires, and its controls. The work packages it describes stay proposals on Implementation Assignments until the user declares them; this page declares nothing.

The evidence field states the evidence a package requires. It is not an observation: what an executor observed and reports is the evidence of an assignment on Implementation Assignments, and whether a package was accepted is stated only by a record on Acceptance Records.

Only pwc-wp-8 is drafted. The acceptance criterion is the user's own acceptance condition for the reader-scaling assignment; the other fields describe that assignment's scope as the user gave it. The entries for pwc-wp-1 to pwc-wp-7 are not drafted.
