Implementation Assignments

This page records implementation assignments given to Claude Code, and the proposals they bring with them. It is the authority for exactly that: that an assignment was given, what it asks for, and what its executor reports. It is not a Work declaration page. A proposal below uses data-proposed-topic, data-proposed-from, data-proposed-relation and data-proposed-to, never data-topic or data-from, so the ordinary Work reader never reads a proposal as a declaration. A proposal has no work status. It becomes Work only when the user declares it on a Work page, under the same ID.

An assignment does not change a status or a dependency on the Work Breakdown or the CTM plan page. An execution by Claude Code is not an acceptance.
