Regular Catalog WBS Dictionary

Draft. This page is not a source of the project CTM and declares nothing. It proposes what the WBS Dictionary of the proposed Deliverable tm-regular-catalog (the Work Item topic-maps-regular-hyperdoc, "Regular HyperDoc Catalog with a Navigable Project Topic Map") would state, in the form of the CTM Plan Page WBS Dictionary: for each proposed work package its scope and exclusions, acceptance criterion, authority, effect, the evidence it requires, and its controls. The work packages stay proposals on Implementation Assignments until the user declares them.

The scope field ends with what the package excludes. The evidence field states the evidence a package requires; it is not an observation. What an executor observed and reports is the evidence of an assignment on Implementation Assignments; an independent review is a report of its own; and whether a package was accepted is stated only by a record on Acceptance Records, which does not exist for any of these packages. A control marked planned has no test yet; external runs outside this repository.

This scope is distinct from tmd-deployment, the separate staging Catalog (a proposal of the HyperDoc reading Deploying Topic Maps with HyperDoc), and from project-work-ctm-exchange, the exchangeable project CTM. Neither is redefined here and none of their deliverables is repeated: the staging package is context for package 5, not part of it.
