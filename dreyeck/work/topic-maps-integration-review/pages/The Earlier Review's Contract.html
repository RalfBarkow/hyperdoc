The Earlier Review's Contract

The earlier review of the b2eecffa packaging candidate (this reading's overview is its successor, not its replacement) has a test called DECLARED-PATHS-AGREE. It failed in the integration worktree. This page says what it protected and why, and what was done.

What it protects

One historical change set: the packaging candidate at the commit where it is complete, 8e64e718, against its base 53ee9993. At that commit Git changes exactly the 73 declared paths, and the 23 tested files have the bytes recorded when their tests ran; at the first packaging commit 7080162b only 66 paths match, because the Linux evidence came later. The facts and the results.

Why it failed: scope, not regression

The check compared the working tree with the declaration, so any change made after 8e64e718 made it fail, whatever it was. The integration changes seven of the protected files on purpose and adds files elsewhere. A genuine regression would be a different thing: an unexpected modification of a protected file.

What was done, and what was not

  • declared-paths-agree-p now compares Git's changes between the base and the reviewed head, not the working tree.
  • tested-files-match-at-p checks the 23 recorded SHA-256 against the bytes at that head.
  • unexpected-drift reports a protected file changed since, unless one of seven named successor changes accounts for it, each with its reason.
  • Not done: the declared list was not extended, no check was removed, no extra file is accepted. The reviewed pin lines of the Workspace are kept as a historical excerpt, because the file they came from legitimately changed.

It can still fail

Positive controls: an extra changed path, a missing path, an undeclared path, an altered tested file, an unlisted modification of a protected file and an empty allowance each make the contract fail or report; four mutants of the contract (an unlisted file drifting, a successor entry removed, the wrong head, a declared path dropped) are each killed. Its second test procedure (the proposals') fails at 8e64e718 too and was not touched.
