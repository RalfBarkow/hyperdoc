What it does not establish

  • The old search is not an independent oracle: it shares equal-topics-p, the merge primitives and the serializer with the new one. A defect in those would survive every comparison. The reviewer supplied independent support for the identity rule from the public Topic Maps data model text.
  • The project CTM never merges two Topics. It cannot show the preference path; the staged-import tests, the fixtures and the mutants do.
  • The generators use a fixed seed and mostly Names and Associations; eight mutants are eight perturbations.
  • Tiny or first-pair-heavy maps are slower with the index (measured). That is a tradeoff, not a changed meaning.
