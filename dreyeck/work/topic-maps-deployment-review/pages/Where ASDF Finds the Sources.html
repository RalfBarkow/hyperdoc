Where ASDF Finds the Sources

ASDF finds a system through its source registry: the trees it is told to search. The variant's wrapper sets that registry to the runtime's sources, then the verified snapshot, then HyperDoc's own source: the registry line. Its startup script, like the production one, ignores every inherited configuration.

Before it serves, the variant asks ASDF where each Topic Maps system comes from. topic-maps-origins requires that all five come from one root and that this root verifies as the snapshot. The systems are defined in the snapshot's own topic-maps.asd.

In the package

The package contract printed one ASDF-ORIGIN line per system: every Topic Maps system from the snapshot, dreyeck from its own store source. The check also searched every registry tree for topic-maps.asd and found exactly one. The claim.
