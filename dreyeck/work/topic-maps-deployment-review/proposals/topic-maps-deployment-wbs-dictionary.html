Topic Maps Deployment WBS Dictionary

Draft. This page is not a source of the project CTM. It proposes what the WBS Dictionary of the proposed Deliverable tmd-deployment would state, in the form of the CTM Plan Page WBS Dictionary: for each proposed work package its scope, acceptance criterion, authority, effect, the evidence it requires, and its controls. The work packages stay proposals on Implementation Assignments until the user declares them; this page declares nothing.

The scope field ends with what the package excludes. The effect field names the files of the repository the package adds or changes. The evidence field states the evidence a package requires; it is not an observation. What an executor observed and reports is the evidence of an assignment on Implementation Assignments, and whether a package was accepted is stated only by a record on Acceptance Records. A proposed package cannot be accepted until it is declared.

The summary element tmd-2 has no entry: its three work packages have one each.

The user decides whether the package is accepted; an executor's report is evidence, not a decision. A correction changes tested files and needs the user's authorization.
