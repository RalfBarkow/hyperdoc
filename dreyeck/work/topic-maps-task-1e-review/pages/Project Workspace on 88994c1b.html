The project suites

The suites record: the Project suite on the re-pinned tree with the original CTM passes (265 source checks, 186 read-back checks in 10.9 s, 125 acceptance checks). On the previous pin the same check failed for the Stage 1 CTM: see the next page.

Real regression or load?

No regression is seen: every semantic observation (the model counts, the CTM digest, the refusal state, the suites' check counts) equals the previous pin's, and the times are lower. The tool-level evidence that the output is unchanged is the Task 1E review's, not this page's: the Association merge order and results are the review's subject. Load matters: the same configuration took 21.9 s at load above 30 and 11.6 s at load 9. The runs here are single observations of each configuration, except the two Git-checkout runs of the Stage 1 CTM.
