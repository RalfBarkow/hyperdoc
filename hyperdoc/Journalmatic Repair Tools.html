Journalmatic Repair Tools

hyperdoc

Journalmatic currently ships two bounded repair operations: rectify chronology and gentle compaction.

Rectify Chronology

The chronology fixer in client/modules/chrono-fix.js sorts journal actions by date. It is intentionally narrow. It does not claim to repair every journal problem. It only addresses chronology drift.

journalmatic-rectify-chronology-example

Gentle Compactor

The gentle compactor in client/modules/compact-gentle.js keeps the last edit in a short run of edits to the same item, while leaving create, add, move, remove, and site-attributed fork actions intact.

This is not arbitrary compression. It is a conservative policy aimed at reducing journal bloat without changing the visible page state.

journalmatic-gentle-compactor-example

Why these tools matter

The two operations define a useful repair style for HyperBook as well: constrained, named, inspectable repairs rather than one opaque “fix journal” command.
