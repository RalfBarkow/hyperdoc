Surface and Artifact Answers

This page defines the operational distinction between immediate terminal responses and durable documentation/code updates.

Inspectable objects

  • Surface Answer
  • Artifact Answer
  • Reconstruction protocol
  • Skillization loop

Distinction

  • Surface Answer: immediate answer in the terminal/Codex session.
  • Artifact Answer: durable answer in HyperDoc/FedWiki/Lisp source artifacts.

Required behavior

  1. Every response provides a Surface Answer.
  2. If the request changes behavior, documentation, or workflows, also provide an Artifact Answer.
  3. For conceptual-only turns, include artifact deltas as a plan unless explicitly skipped.

Reconstruction protocol

  • Process trace: what was checked and decided.
  • HyperDoc delta: page/section updates.
  • Lisp delta: topic/object/view/function updates.
  • FedWiki delta: slug/title/summary/references and daily anchors.
  • Replay checks: JSON parse, journal integrity, and link resolution checks.

Skillization loop

Repeated patterns are extracted into reusable routines so the runtime can execute them directly, instead of requiring one-off assistant steps each time.
