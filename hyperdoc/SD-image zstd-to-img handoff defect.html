Diagnosis

Step 1 outputs .zstd. Step 2 requires .img. The transition .zstd -> .img was implicit and therefore a defect in procedure relation modeling.

Patch target

Patch the relation between step 1 and step 2 by inserting an explicit decompression step with verification that .img exists and is carried into the flash step.

Follow-up handoff: filename preservation

A second relation defect exists one step earlier: plain wget "$LATEST_URL" for Hydra latest/download/1 can save as file 1. Decompression expects a named .img.zst artifact.

The patch is in the download step itself: wget --trust-server-names "$LATEST_URL", which preserves the final redirected artifact filename and satisfies the decompression precondition.

Mechanism in this command path: the redirect target URL already contains the concrete filename, and wget keeps that redirected server name when --trust-server-names is used.

Postcondition: the local directory has a new nixos-image-sd-card-*.img.zst file and no rename from 1 is needed before decompression.
