This slice reframes the existing pane-level Connect chrome as a Dock: the place where a pane exposes what can currently be done with the thing in front of you. The current Dock keeps three sibling actions visible together: Connect, Inspect, and Annotation.

Dock framing

The Dock is not a parallel subsystem. It reuses the existing DOM-annotation surface, hidden eval-button submit bridges, and inspector pane wiring that already powered Connect. The visible pane row now groups these actions as siblings:

  • Connect: the existing two-anchor relation gesture and request-evidence flow.
  • Inspect: open the current pane object directly.
  • Annotation: open or reopen the generic annotation object for the current pane object.

The existing Connect-state inspection remains available as the separate Connect state action, so the old inspection seam stays reachable.

Annotation object

The new generic annotation object is a specialized dom-relation-annotation, not a sibling substrate. In this slice it points from the generic Annotation topic/object to the current pane object.

The resulting dock-annotation preserves at least:

  • the target object
  • a synthetic target anchor for the current pane object
  • the context view title
  • the generic relation-kind classification slot (annotation)
  • a prefilled note field

Reopening Annotation for the same current object reuses the same inspectable object through the in-image *dock-annotations* registry. This is honest reopenability, but it is not yet durable authored persistence across restart.

Current boundary

The acceptable narrow first slice is what is implemented here: Annotation acts on the current pane object first. It does not yet let you click an arbitrary visible DOM anchor and persist a distinct annotation for that sub-anchor. The naming and object shape keep the door open for that next step.

Zotero as optional Dock capability

Touch-Fahrplan and topic enrichment remain intact, but Zotero is no longer the center of the pane chrome. When the corresponding backend seam is actually available, the Dock may surface a separate Zotero action that opens the existing Touch-Fahrplan topic view. When it is unavailable, the Dock still exists with Connect, Inspect, and Annotation.

Chunk walkthrough

  1. Open the topic page Chunk.
  2. Stay on the Content pane view.
  3. Use the Dock row and click Annotation.
  4. Inspect the resulting dock-annotation object.
  5. Use the title-bar Open target action or the target rows to reopen the target object.
  6. Return to Chunk and click Annotation again; the same inspectable annotation object reopens.
