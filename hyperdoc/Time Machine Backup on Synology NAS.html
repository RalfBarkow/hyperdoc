Time Machine Backup on Synology NAS

hyperdoc

This page captures the Synology-specific server-side setup needed to expose a working SMB Time Machine destination to macOS.

Enable SMB

  1. Log in to DSM as an administrator.
  2. Open the Synology file services settings.
  3. Enable SMB service.
  4. Apply the change and confirm the NAS is reachable over SMB from the Mac.

Synology documents Time Machine setup through SMB rather than AFP for current DSM/macOS workflows.

Enable Bonjour / Time Machine broadcast via SMB

  1. Open the SMB advanced settings in DSM.
  2. Enable the Bonjour advertisement or Time Machine broadcast option for SMB.
  3. Select the shared folder that should be offered to Time Machine.

The expected result is that the Time Machine target becomes discoverable to macOS as a network backup destination rather than only as a generic SMB share.

Configure a dedicated shared folder

  1. Create or choose a shared folder dedicated to Time Machine backups.
  2. Avoid mixing unrelated NAS file-serving workflows into the same folder if you want clearer permissions and quota control.
  3. Confirm the folder is selected in the Synology Time Machine/Bonjour SMB settings.

Assign permissions and quota

  1. Create or choose a DSM user account intended for Time Machine access.
  2. Grant that account read/write access to the dedicated backup shared folder.
  3. Set a quota large enough for the expected backup history.
  4. Verify that the account can mount the share from the Mac.

Select the share from macOS

  1. Open Finder -> Network and connect to the Synology NAS.
  2. Mount the Time Machine share with the intended DSM account.
  3. Open System Settings -> General -> Time Machine.
  4. Add the destination and authenticate if prompted.

Common Synology-specific failure modes

  • SMB is enabled, but Bonjour / Time Machine broadcast is not.
  • The share exists, but the selected DSM user lacks write access.
  • The quota is too small for the first full backup.
  • The NAS is visible in Finder, but the Time Machine support setting is not bound to the intended shared folder.

What success looks like

  • The Synology share mounts in Finder with the intended credentials.
  • The share can be selected in Time Machine settings.
  • The first backup starts and later backups continue against the same SMB destination.
