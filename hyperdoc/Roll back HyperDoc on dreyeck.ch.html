Roll back HyperDoc on dreyeck.ch

Revert to a previous NixOS generation if deployment validation fails.

Purpose

Restore a known-good service state quickly using standard NixOS rollback.

Prerequisites

  • Root or sudo access on dreyeck.ch.
  • A previous working system generation exists.

Context

Rollback uses NixOS generation switching, not custom release symlink switching.

Steps

  1. Rollback to the previous generation: 
    sudo nixos-rebuild --rollback switch
  2. If you need a specific generation, activate it directly: 
    sudo /nix/var/nix/profiles/system-<generation>-link/bin/switch-to-configuration switch

Result

The host runs the selected older generation and HyperDoc should return to its previous behavior.
