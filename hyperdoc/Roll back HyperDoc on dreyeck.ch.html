Roll back HyperDoc on dreyeck.ch

Revert to a previous NixOS generation if dry/test/switch verification fails.

Inspectable objects

  • NixOS generation rollback
  • Cautious nixos-rebuild activation sequence

Purpose

Restore the last known-good host state quickly using standard NixOS rollback paths.

Prerequisites

  • Root or sudo access on dreyeck.ch.
  • A previous working generation exists.

Context

Rollback remains in the same NixOS deployment model; no custom symlink release switching is used.

Steps

  1. Rollback to previous generation: 
    sudo nixos-rebuild switch --rollback
  2. If you need a specific generation, activate it directly: 
    sudo /nix/var/nix/profiles/system-<generation>-link/bin/switch-to-configuration switch

Result

The host runs the selected previous generation.
