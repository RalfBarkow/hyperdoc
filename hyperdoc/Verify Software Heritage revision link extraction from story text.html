Verify Software Heritage revision link extraction from story text

hyperdoc

This verification page teaches how to check that the clickable-commit-id path is really producing a Software Heritage revision link from story text.

Minimal example input

See 0123456789abcdef0123456789abcdef01234567
and [https://example.org Example]

Expected output

A passing outcome includes a Software Heritage revision URL with the exact shape https://archive.softwareheritage.org/swh:1:rev:0123456789abcdef0123456789abcdef01234567/. If the same example also includes the supported external-link form, the ordinary URL https://example.org remains present as well.

What to inspect

  • the example in hyperdoc/examples-portable.lisp
  • the FedWiki story-item smoke tests
  • the story-item renderer path that performs the translation

What a passing outcome looks like

  • the commit hash is no longer inert text
  • the rendered/extracted URL list contains the Software Heritage revision URL
  • the external link remains present when expressed in the supported syntax
