Stale target coordinates

hyperdoc

A precision-guided strike can still produce mass civilian harm when the underlying target coordinates, site status, or site classification are obsolete. HyperDoc uses this page for the durable distinction between a precise weapon and a correct target.

Why precise weapons still hit the wrong place

The weapon can perform exactly as designed while the strike still lands on an unlawful or unintended site. In that failure mode, precision is not the remedy because precision only guarantees accurate delivery to the coordinates supplied.

How stale target data persists

  • old intelligence remains in the target package after the site changes
  • a civilian site inherits earlier military-site assumptions
  • adjacent military activity causes a nearby civilian structure to be read through outdated mapping
  • operators trust previously approved coordinates without demanding fresh confirmation

Relation to target validation

Stale coordinates are the data problem. Target validation is the process problem that should detect and correct stale data before launch. When both fail, a strike can look technically precise while remaining operationally wrong.

Boundary

This concept is not the same as weapon malfunction, navigation drift, or guidance failure. It specifically names a case where the coordinates may be accurate as coordinates, but no longer correct as a representation of the intended target.
