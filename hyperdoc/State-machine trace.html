State-machine trace

hyperdoc

A State-machine trace is the ordered, evidence-bearing account of one run: visited states, taken or skipped transitions, timestamps where available, and explicit failure boundaries.

Trace versus explanation

A trace is not only a prose recap. It is data attached to a run object that can be rendered differently in trace, timeline, or failure-analysis views.
