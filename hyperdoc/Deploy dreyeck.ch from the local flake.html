Deploy dreyeck.ch from the local flake

Activate the dreyeck-ch NixOS host configuration over SSH from your local working tree.

Purpose

Promote the locally verified flake state to the target host without server-side branch assembly.

Prerequisites

  • Verify HyperDoc locally before deployment has passed.
  • SSH access to dreyeck.ch (or its admin SSH target).

Context

hauptsache should be verified locally and deployed from the local flake; the server should not be repaired by checking out that branch directly.

Steps

  1. Deploy from a Linux controller host: 
    nixos-rebuild --flake .#dreyeck-ch --target-host <ssh-target> switch
  2. If the controller is macOS or non-Linux, use a Linux build host: 
    nixos-rebuild --flake .#dreyeck-ch \
  --build-host <linux-builder> \
  --target-host <ssh-target> \
  switch

Result

The target host switches to the deployed dreyeck-ch generation built from local flake state.
