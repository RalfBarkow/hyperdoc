FedWiki story item rendering trust boundary

hyperdoc/inspector

This page demonstrates the two recent FedWiki story-item rendering hardenings: :html story items now fail closed by default, and the :graphviz story-item path remains text-backed and routed through the shared Graphviz rendering seam.

Inspectable examples

  • (make-fedwiki-html-story-item-blocked-demo) — renders an unsafe-looking HTML item in the default blocked mode.
  • (make-fedwiki-html-story-item-trusted-demo) — renders a small trusted HTML item with the explicit trust binding.
  • (make-fedwiki-graphviz-story-item-shape-demo) — proves that Graphviz uses story item text, not data["dot"], as the canonical DOT source.
  • (make-fedwiki-story-item-rendering-demo-set) — opens all three examples as one inspectable list.

What to look for in the inspector

Each example object has views for Overview, Rendered HTML, Source shape, Contract, and Related examples.

Example Expected observation
:html blocked The rendered output contains the blocked-message text and escaped source; it must not emit a raw <script> tag.
:html trusted The rendered output is raw only because the demo dynamically binds *render-unsafe-html-story-items* to true.
:graphviz The rendered output contains the shared Graphviz placeholder and the text-backed DOT, while the deliberately wrong data["dot"] value is absent.

Boundary

This page demonstrates behavior. It does not make remote FedWiki HTML trusted, and it does not move Graphviz rendering policy into the FedWiki adapter. The adapter remains a dispatch seam; the shared Graphviz runtime remains the rendering seam.
