Why this source belongs in HyperDoc

  • It exposes a small but real Common Lisp software ecology: utilities, parser, typed layers, planning language, planner, and an experimental literate tool.
  • It keeps manuals and downloadable software close together, which makes it useful as a documentation-surface case.
  • It links Lisp implementation practice to planning-language work through PDDL, Opt, and Optop.
  • It contains one especially relevant Lisp title, A framework for maintaining the coherence of a running Lisp, that should be connected to HyperDoc's existing source/image boundary discussions.

What to import

  • the software stack around YTools, Nisp/YNisp, Nity, Opt, and Optop
  • the planning-language thread from PDDL to Opt
  • the title-level anchor for the running-Lisp coherence paper
  • the cautionary Litlisp experiment

What not to import yet

  • the entire publication list as one topic per paper
  • homepage miscellany such as blog links, style notes, or Emacs package odds and ends
  • software-installation instructions as if they were current operational guidance for this repository

The right import boundary is therefore a narrow source/software cluster, not a full scholarly bibliography and not a nostalgia mirror of the whole site.
