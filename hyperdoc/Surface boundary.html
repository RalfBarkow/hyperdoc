Surface boundary

hyperdoc

A Surface boundary is the explicit rule set that states what one surface allows, what it forbids, and how it connects to adjacent surfaces without collapsing them together.

Inspectable objects

  • Surface boundary
  • HyperDoc surface boundaries
  • (make-dmx-workspace-repair-diagnostic-surface-instance) Boundary state
  • (make-dmx-repair-console-mutation-surface-instance) Boundary state

Worked examples

  • Documentation surfaces: page/topic/runtime/FedWiki layers remain distinct.
  • DMX repair: read-only triage remains separate from explicit-auth mutation.
  • Observed failure: blocked evidence remains visible as a failure surface instead of widening the mutation surface silently.
