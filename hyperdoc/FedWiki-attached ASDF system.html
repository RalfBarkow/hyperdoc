FedWiki-attached ASDF system

A FedWiki-attached ASDF system is a local file-backed system home page for a FedWiki page identity. The FedWiki client URL is an identity name; SLY and ASDF work from local file-backed assets in the page asset directory on disk.

Contract

The durable chain is: 

FedWiki page identity: kioskbeerli
-> local page asset root: ~/.wiki/wiki.ralfbarkow.ch/assets/pages/kioskbeerli/
-> ASDF entrypoint: kioskbeerli.asd
-> ASDF system object: :kioskbeerli
-> inspector Overview / system home page

The home object records the slug, local asset root, ASDF entrypoint pathname, system name, optional test system, source directory, package state, examples, tests, actions, lookup trace, and recovery routes. Its default inspector Overview starts with reading-comprehension answers rather than raw slots.

MREPL flow

(defparameter *kioskbeerli-home*
  (hyperdoc:make-fedwiki-attached-asdf-system
   :slug "kioskbeerli"
   :site-root #p"/Users/rgb/.wiki/wiki.ralfbarkow.ch/"
   :system :kioskbeerli
   :system-file "kioskbeerli"
   :test-system :kioskbeerli/tests))

(hyperdoc:asdf-system-home-page-of *kioskbeerli-home*)
(hyperdoc:load-fedwiki-attached-asdf-system *kioskbeerli-home*)
(clog-moldable-inspector:clog-inspect :object *kioskbeerli-home*)

Lookup failure boundary

If the page-local ASDF route fails, HyperDoc returns an inspectable lookup-failure object. The failure report lists the local FedWiki page asset .asd and the workspace source .asd, with availability, tried state, recovery action, and condition text.

The report also states the package-reader consequence: a form such as kioskbeerli:make-demo-dashboard cannot even be read until a successful load creates the KIOSKBEERLI package.

Boundary

This protocol does not fetch http://localhost:3000/view/kioskbeerli, does not require the browser to be open, and does not write DMX. The URL remains a FedWiki client page identity; the operational route is through local file-backed assets, starting from the local pathname /Users/rgb/.wiki/wiki.ralfbarkow.ch/assets/pages/kioskbeerli/kioskbeerli.asd.
