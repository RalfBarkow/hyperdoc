Function: HYPERDOC::PREPARE-AARCH64-IMAGE-TOPIC

HYPERDOC::PREPARE-AARCH64-IMAGE-TOPIC returns an inspectable hyperdoc::topic object representing this preparation topic. 

(hyperdoc::prepare-aarch64-image-topic)

Quick check: 

(fboundp 'hyperdoc::prepare-aarch64-image-topic)

Fix: undefined-function error

If you get undefined-function HYPERDOC::PREPARE-AARCH64-IMAGE-TOPIC, the running Lisp image does not yet have the updated hyperdoc/core.lisp definitions loaded.

1. Reload HyperDoc systems in the same image: 

(require :asdf)
(asdf:load-system :hyperdoc :force t)
(asdf:load-system :hyperdoc/server :force t)

2. Re-check function availability: 

(fboundp 'hyperdoc::prepare-aarch64-image-topic)

3. If still NIL, restart the server process (or ./dev.sh) and retry.

Goal

Produce a verified *.img artifact from a known aarch64 source, ready to flash and boot.

Inputs

  • target architecture: aarch64-linux
  • source path:
    • official prebuilt image (nixos-sd-image-*-aarch64-linux.img.zst)
    • or project build output (...system.build.sdImage)
  • host toolchain for decompression/checksum verification

Procedure

  1. Select one source of truth (official prebuilt or project build).
  2. Download/build the artifact and record provenance (URL/commit/date).
  3. Decompress (zstd -d) when needed.
  4. Verify artifact integrity (size/checksum if available).
  5. Confirm filename and architecture include aarch64-linux.

Acceptance

  • artifact exists as .img and is readable
  • architecture is confirmed as aarch64 target
  • provenance is recorded for later replay/debugging
