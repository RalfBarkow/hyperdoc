Dreyeck Transition Plan for upstream main into hauptsache

hyperdoc

This page turns the bucketed dreyeck extraction plan into an implementation-ready transition surface. The durable object is a git-dreyeck-transition-plan that records, for each bucket, the exact path list, target destination, dependency direction, transition mode, core continuation point, and validation proof.

The current transition plan keeps the same four buckets:

  • runtime-hooks
  • local-deployment
  • page-content-overlays
  • glue-code

What changes in this slice is not the classification itself, but the downstream destination and the split protocol. That keeps the eventual dreyeck extraction inspectable before any file moves happen.

Why this is still preparation

This page still does not create the dreyeck subsystem or move files. It records the intended destinations and proof obligations so the later split can be executed as a replayable change instead of an ad hoc refactor.
