Parsing SHOP3 Introduction into Topics

hyperdoc/shop3

This page demonstrates the repo-local parser for turning the SHOP3 manual Introduction into HyperDoc topic candidates. The parser is part of the optional hyperdoc/shop3 system and accepts the source URL as an explicit keyword argument: 

(parse-shop3-introduction-topics html
                                 :source-url "https://shop-planner.github.io/#Introduction")

The examples below are real HyperDoc examples. Each rendered defexample form gets a ► play button. Clicking the button runs that example and opens the result in a new pane.

2. Parse the Introduction fragment

This example parses a compact local HTML fragment shaped like the SHOP3 manual Introduction. It does not perform network access. The URL is provenance metadata supplied by the caller.

shop3-introduction-parse-source-url-example

3. Verify source URL propagation

This example checks that every generated topic carries the exact :source-url supplied to the parser.

shop3-introduction-topic-source-url-example

4. Summarize generated topic kinds

This example summarizes the parser output as root chapter, concept topics, and distinctive-characteristic topics.

shop3-introduction-topic-kinds-example

Expected interpretation

The parser produces plain Lisp topic plists. The first item is a :source-chapter root topic. Paragraphs become :concept topics. List items become :distinctive-characteristic topics.
