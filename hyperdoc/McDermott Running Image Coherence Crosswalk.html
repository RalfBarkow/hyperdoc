Key Insight for HyperDoc

HyperDoc already solves the operational problem: how to reload, inspect, and test a running system.

McDermott provides the missing semantic model: a first-class dependency graph over runtime objects, enabling principled, minimal, and correct rederivation.

The integration path is therefore not replacing existing pages, but introducing a new topic layer that explains:

  • what exactly is being kept coherent,
  • how dependencies are represented,
  • and how updates propagate through the running image.
