State machine

hyperdoc

State machine is a first-class HyperDoc runtime abstraction: a reusable definition object plus one or more concrete run objects. Pages explain the abstraction, topics give it stable semantic handles, and runtime objects provide the inspectable data from which visualizations are derived.

Definition and run

In HyperDoc, a state machine must exist at two levels:

  1. a reusable state-machine-definition object
  2. a concrete state-machine-run object

This keeps durable machine structure separate from one particular traversal, while still allowing both to be inspected through generic views.

Worked example boundary

DMX auth is now one worked example instance of the generic machine model. The auth pages keep their specialized teaching views, but they no longer define what a state machine is.
