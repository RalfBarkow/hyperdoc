Python json.tool Source and Usage

python3 -m json.tool is useful as a fast syntax check for FedWiki page JSON files.

Inspectable objects

  • Python json.tool source

Where is the source code?

In CPython, the module source is: Lib/json/tool.py.

On a local machine, print the installed module path with: 

python3 - <<'PY'
import json.tool
print(json.tool.__file__)
PY

Example local path observed in this environment: /usr/local/Cellar/python@3.14/3.14.0/Frameworks/Python.framework/Versions/3.14/lib/python3.14/json/tool.py.

Usage in this workflow

Validate a FedWiki page file: 

python3 -m json.tool /Users/rgb/.wiki/wiki.ralfbarkow.ch/pages/<slug> >/tmp/<slug>.json

This validates JSON syntax/parsing only. It does not validate journal chronology/replay semantics.
