DM6 Elm Artifact Inspector Runbook

hyperdoc

This page documents the durable operator workflow for treating dm6-elm as an inspectable HyperDoc object. The source implementation lives in hyperdoc-explorer/dm6-elm-artifact-inspector.lisp.

Normal entry point

Open the artifact inspector, regenerate the Nix graph SVG, regenerate the side-by-side comparison files, and open the comparison surface: 

(dm6-open!)
  • (dm6-open!)
  • (dm6-inspect-artifact! *dm6-artifact*)
  • (dm6-inspect-side-by-side-page! *dm6-artifact*)

Build and repair commands

  • (dm6-check-side-by-side-assets!)
  • (dm6-build-appembed-bundle! *dm6-artifact*)
  • (dm6-build-main-bundle! *dm6-artifact*)
  • (dm6-write-nix-graph-svg! *dm6-artifact*)
  • (dm6-write-side-by-side! *dm6-artifact*)

Expected inspector tabs

  • Version metadata: Git, Elm, bundle sizes, bundle SHA values.
  • Nix metadata: nix flake metadata output.
  • Nix graph SVG: server-side dot -Tsvg output.
  • Build commands: exact Elm bundle build commands.
  • Browser: embedded AppEmbed and standalone Elm shell side by side.

Failure policy

Do not call views:add-asset-path from top-level SLY functions. Asset route registration belongs inside the rendering body of views:html-view; otherwise VIEWS:*VIEW-ACCUMULATOR* is unbound.
