Record dreyeck.ch generation before rebuild

Capture generation and active-system references before any activation change.

Inspectable objects

  • dreyeck generation record
  • Deployment command locality
  • NixOS generation rollback

Purpose

Keep exact rollback references for the system that was active before deployment.

Prerequisites

  • Back up dreyeck.ch before deployment completed.
  • Root or sudo privileges on dreyeck.ch.

Context

Store this snapshot before any dry-activate, test, or switch run. Run this command on the local controller, targeting dreyeck.ch via SSH.

Steps

  1. Run on local controller (executes on dreyeck.ch): write rollback reference file: 
    ssh <ssh-target> 'sudo sh -c '"'"'{ echo "# $(date -Is)"; echo; echo "## generations"; nixos-rebuild list-generations; echo; echo "## current-system"; readlink -f /run/current-system; echo; echo "## booted-system"; readlink -f /run/booted-system; } > /root/pre-hyperdoc-backup/rollback-reference.txt'"'"''

Result

/root/pre-hyperdoc-backup/rollback-reference.txt contains pre-deploy generation and system links.
