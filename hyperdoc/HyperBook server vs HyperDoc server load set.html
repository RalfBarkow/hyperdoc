HyperBook server vs HyperDoc server load set

HyperBook server vs HyperDoc server load set is the distinction between reaching the generic server implementation and reaching the full HyperDoc-specific set of systems expected for the deployed experience.

The distinction

Loading :hyperbook/server reaches the generic server implementation. Loading :hyperdoc/server reaches the same implementation plus the HyperDoc-specific systems needed for the intended example/discovery surfaces.

Why it matters operationally

Two startup paths can both serve pages successfully and still differ in their discoverable HyperDoc surfaces. That is why “the server works” is weaker than “the intended HyperDoc load set is active.”
