Scoped example parity

Scoped example parity means that localhost and dreyeck expose the same intended example scopes for the ASDF systems that are meant to be loaded in that environment.

Inspectable objects

  • Scoped example parity
  • Portable examples
  • Portable example scope
  • Example system boundary
  • Live parity evidence

What parity means here

In this repo, parity is not a root-global count of all examples. It is a match in the intended system-scoped layers: base hyperdoc, portable hyperdoc/examples, and ops-specific hyperdoc/examples/ops.

Why parity can fail

The most important failure mode in this slice was a Startup load-set mismatch: the server could start, but the runtime image still under-loaded the example systems.

How to confirm it

Use both:

  • UI evidence from the Examples surface
  • runtime evidence from Probe dreyeck runtime load set
