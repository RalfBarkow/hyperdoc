Zotero library bridge for HyperDoc

hyperdoc

This slice adds one narrow read-only bridge from HyperDoc into a local Zotero library. The bridge takes a Zotero database path, a Zotero storage root, and optional note roots, queries bibliographic items through sqlite3, discovers child attachments, and returns typed inspectable objects rather than opaque path strings.

Inspectable objects

  • Zotero library
  • Zotero attachment
  • Attachment path resolution
  • (make-default-zotero-library-bridge)
  • (mind-and-mechanism-zotero-title-query)
  • (mind-and-mechanism-zotero-item-id-query)
  • (mind-and-mechanism-zotero-resolution-report)

Configuration boundary

The default constructor first respects environment overrides, then falls back to the conventional local Zotero locations under ~/Zotero/.

  • HYPERDOC_ZOTERO_DB_PATH
  • HYPERDOC_ZOTERO_STORAGE_ROOT
  • HYPERDOC_ZETTELKASTEN_ROOTS as a colon-separated list
  • HYPERDOC_SQLITE_PROGRAM if sqlite3 is not on PATH
  • HYPERDOC_ZOTERO_DEMO_DB_PATH, HYPERDOC_ZOTERO_DEMO_STORAGE_ROOT, HYPERDOC_ZOTERO_DEMO_TITLE, HYPERDOC_ZOTERO_DEMO_ITEM_ID, and HYPERDOC_ZOTERO_DEMO_ATTACHMENT_KEY for the concrete live demonstrator

The bridge is intentionally read-only. It does not sync Zotero, edit items, or import a whole note system into HyperDoc.

Supported entry points

The named lookup operations are:

  • lookup-zotero-items-by-title for exact or loose title lookup, returning bibliographic hits plus a zotero-title-query object
  • lookup-zotero-item-by-id for deterministic item-id lookup, returning a bibliographic hit plus a zotero-item-id-query object
  • list-zotero-attachments-for-item for child attachment discovery
  • resolve-zotero-stored-attachment-path for stored-file resolution
  • resolve-zotero-title-to-candidate-pdf-reports and resolve-zotero-title-to-local-pdf-report for report-oriented title resolution

The main object for user-facing title resolution remains hyperdoc::zotero-title-resolution-report. Deterministic verification can use the item-id path directly.
