Add or edit an annotation from a path context menu

hyperdoc

Add or edit an annotation from a path context menu is the task page for the current merge-forecast row interaction pattern. It documents how the existing context commands open inspectable objects instead of mutating files directly.

Task sequence

  1. Open a merge-forecast path list such as 👀hauptsache-only-files, 👀upstream-only-files, or 👀overlapping-paths.
  2. Right-click the row for the path you want to inspect.
  3. Choose Details to open the row target object itself.
  4. Choose Add annotation to open a draft annotation object if no explicit annotation exists yet.
  5. Choose Edit annotation when an explicit annotation already exists for the path.
  6. Choose Related decisions to inspect path decisions already attached to that path.

Worked example

For the current repo history, the worked example path is hyperbook-server/assets/hyperbook-server/js/url.js. It already has an explicit annotation, so Edit annotation is the concrete command to use there, while Add annotation remains the generic draft-opening path for rows without a recorded annotation.

Implementation boundary

  • The menu is rendered by custom HyperDoc JS/CSS, not by native browser context menus.
  • The commands are hidden object refs rendered into the DOM and activated by the custom menu.
  • The current behavior opens inspectable objects; it does not persist annotation edits to source yet.
