Gate rule

A page is commit-blocked when checker findings include any of: CREATION, CHRONOLOGY, REVISION, or MALFORMED.

Lisp source

These functions define the gate findings set, derive page-level gate findings, and return a pass/fail gate decision.

journalmatic-commit-gate-findings journalmatic-commit-gate-pass-p journalmatic-commit-gate-script-example

Operational sequence

  1. Run python3 -m json.tool for JSON syntax and structure.
  2. Run journal checker and compute commit-gate findings.
  3. If any gate findings remain, repair journal before commit.
  4. Commit journal repairs separately from docs/topic updates.
