Back up dreyeck.ch before deployment

Create a rollback backup set on the target host before any nixos-rebuild activation.

Inspectable objects

  • dreyeck backup before rebuild
  • Deployment command locality

Purpose

Preserve configuration and HyperDoc data so rollback and manual recovery remain possible.

Prerequisites

  • SSH access to dreyeck.ch.
  • Root or sudo privileges on the target host.

Context

This is the first deployment step. Do this before dry-activate, test, or switch. Run these commands on the local controller, targeting dreyeck.ch via SSH.

Steps

  1. Run on local controller (executes on dreyeck.ch): create backup directory: 
    ssh <ssh-target> 'sudo mkdir -p /root/pre-hyperdoc-backup'
  2. Run on local controller (executes on dreyeck.ch): back up /etc/nixos: 
    ssh <ssh-target> 'sudo tar czf /root/pre-hyperdoc-backup/etc-nixos-$(date +%F-%H%M%S).tar.gz /etc/nixos'
  3. Run on local controller (executes on dreyeck.ch): back up HyperDoc data/workspace snapshots (best effort for missing paths): 
    ssh <ssh-target> 'sudo tar czf /root/pre-hyperdoc-backup/hyperdoc-data-$(date +%F-%H%M%S).tar.gz /var/lib/hyperdoc /home/rgb/workspace/hyperdoc 2>/dev/null || true'

Result

Timestamped backup archives exist under /root/pre-hyperdoc-backup.
