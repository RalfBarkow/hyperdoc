Manual staging plan for codex handover consolidation

The slice is good. The next step is to cut a clean commit by resetting the index for the affected prompt files back to HEAD, then restaging only the slice hunks.

Recommended sequence

nix develop

# 1) Remove unrelated staged prompt artifacts from the index.
git restore --staged \
  "hyperdoc/Best Codex Handover for HyperDoc.html" \
  "hyperdoc/Codex prompts v2 for HyperDoc.html" \
  "hyperdoc/Updated Codex prompts for HyperDoc.html"

# 2) Reset mixed files back to HEAD in the index only.
#    This keeps your worktree edits, but clears older staged state.
git restore --staged AGENTS.md \
  "hyperdoc/Best handover to Codex for HyperDoc.html"

# 3) Stage the files that belong wholly to this slice.
git add \
  "hyperdoc/Codex handover for HyperDoc.html" \
  hyperdoc/page-id-migration.md \
  hyperdoc/rename-aware-repair.md

# 4) Stage only the intended hunks from the mixed files.
git add -p AGENTS.md

git add -p "hyperdoc/Best handover to Codex for HyperDoc.html"

# 5) Inspect exactly what will go into the commit.
git diff --cached --stat

git diff --cached -- \
  AGENTS.md \
  "hyperdoc/Codex handover for HyperDoc.html" \
  "hyperdoc/Best handover to Codex for HyperDoc.html" \
  hyperdoc/page-id-migration.md \
  hyperdoc/rename-aware-repair.md

# 6) Commit only when the staged diff is clean.
git commit -m "docs(codex): consolidate HyperDoc handover prompts"

What to stage in patch mode

  • AGENTS.md: only the repo-git preference line that prefers nix develop --command git ....
  • hyperdoc/Best handover to Codex for HyperDoc.html: only the continuity-shell clarification that it contains no reusable prompt body.

Why this works

git restore --staged resets the index to HEAD without discarding your worktree edits. That gives you a clean base for git add -p, which is the safest way to isolate this slice from older staged prompt work.

After the commit

Your unrelated prompt artifacts and any non-slice edits will still be present in the worktree. They just will not be part of this commit.
