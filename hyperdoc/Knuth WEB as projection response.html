Knuth WEB as projection response

hyperdoc

Knuth's WEB response is projection-oriented. The source can be arranged in reader order while a machine-order projection remains available for execution. This is related to the readability problem, but it is not the same operation as the Kernighan/Plauger style-training cycle.

Projection boundary

  • Reader order: organize program material so the human reader meets motivation, vocabulary, mechanism, and evidence in a useful order.
  • Machine-order projection: preserve the executable order required by the programming language or build process.
  • Boundary: WEB projects a program for readers; Kernighan/Plauger train style judgment by criticism and rewrite.
