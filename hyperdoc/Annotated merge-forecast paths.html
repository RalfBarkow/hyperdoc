Annotated merge-forecast paths

hyperdoc

Annotated merge-forecast paths is the current HyperDoc skill for treating a merge-forecast row as more than plain text. The row target is an inspectable object, the annotation is another inspectable object, and a custom context-menu layer exposes commands without executing the merge.

This implementation is honest about its current mechanics: inspectable row target objects, hidden action refs, custom context-menu JS/CSS, and object-ref based action transport. It is not yet a generic DMX port.

Inspectable objects

  • Annotated merge-forecast paths
  • Context commands for inspectable path rows
  • hyperdoc-upstream-main-into-hauptsache-url-helper-asset-path-context-surface
  • hyperdoc-upstream-main-into-hauptsache-url-helper-asset-path-item
  • hyperdoc-upstream-main-into-hauptsache-url-helper-asset-path-annotation
  • hyperdoc-upstream-main-into-hauptsache-merge-forecast

Current command set

  • Details: open the git-forecast-path-item target object for the row.
  • Add annotation: open a draft or explicit git-path-annotation target for the path.
  • Edit annotation: open the explicit annotation object when one already exists.
  • Related decisions: open the path item's Related decisions view.

Worked example

The current worked example path is hyperbook-server/assets/hyperbook-server/js/url.js. In the current merge-forecast it is a hauptsache-only path with an explicit path annotation about runtime URL-helper ownership and merge policy.
