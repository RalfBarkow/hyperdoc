Reconstruction protocol

hyperdoc

The reconstruction protocol requires each answer to be replayable from explicit process trace, artifact deltas, and verification checks.

Inspectable objects

  • Reconstruction protocol
  • Surface Answer
  • Artifact Answer

Required elements

  • Process trace: what was inspected/decided.
  • Artifact deltas: exact files/pages/topics/twins updated.
  • Replay checks: commands or steps that prove current state.
