HyperDoc three-mode DMX auth crosswalk

hyperdoc

HyperDoc three-mode DMX auth crosswalk is the durable learning surface for the three repair-console input modes: username/password, authorization header, and bearer token. Each concrete example is a first-class dmx-auth-path-example. It keeps the chosen mode, normalized mode, derived Authorization header, Credentials-like backend shape, bootstrap request shape, later session-backed request shape, and source evidence inspectable without changing the guarded execution boundary.

The three modes

  • username/password: operator enters username plus password, HyperDoc derives the equivalent Basic Authorization header, and a later JSESSIONID session-cookie aftermath becomes inspectable
  • authorization header: operator enters the full header directly; HyperDoc preserves it and can safely decode a Basic example into a Credentials-like structure for display
  • bearer token: operator enters a token, HyperDoc derives Authorization: Bearer ..., and the backend note stays Installation-dependent unless a matching non-Basic AuthorizationMethod or compatible proxy is present

Safe dummy examples

  • username: alice
  • password: example-password
  • authorization header: Basic YWxpY2U6ZXhhbXBsZS1wYXNzd29yZA==
  • bearer token: eyJhbGciOi...example

These are dummy examples for learning and object inspection only. They are not live secrets and they are not copied operator credentials.

DMX-core-native, HyperDoc-derived, and installation-dependent layers

  • DMX-core-native: Authorization header parsing into Credentials, AuthorizationMethod resolution for non-Basic schemes, servlet-session username attachment, and AnonymousAccessFilter fallback
  • HyperDoc-derived: the three operator-facing input modes, the derived Basic header from username/password input, the learning-state machine labels, and the explicit session-cookie aftermath display
  • Installation-dependent: bearer-token success beyond the local UI and whether the running deployment has a matching non-Basic AuthorizationMethod or compatible proxy/gateway boundary
