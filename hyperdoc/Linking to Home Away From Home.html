Linking to Home Away From Home

This page applies the general FedWiki link model to one concrete page: Home Away From Home.

Idea 1: use site plus slug

The page should be named by its site and its slug.

Home Away From Home

Idea 2: this is better than a raw browser URL

The HyperBook form keeps the link inside the inspector model. It says which FedWiki book owns the page and which page is intended. 

<a hyperbook="fedwiki:wiki.ralfbarkow.ch" page="home-away-from-home">
  Home Away From Home
</a>

Idea 3: the fallback should remain visible but secondary

If runtime support is incomplete, the operational fallback is still the local server URL. But that is not the preferred representation. 

http://127.0.0.1:8080/89661-wiki-ralfbarkow-ch/home-away-from-home

Idea 4: this matters because the page is operationally relevant

Home Away From Home matters when discussing landing pages such as home/index.html. So it should be linked in the same way other inspectable workflow pages are linked.
