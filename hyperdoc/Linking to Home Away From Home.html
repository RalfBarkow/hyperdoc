Linking to Home Away From Home

The FedWiki page Home Away From Home should ideally be linked from HyperDoc as a FedWiki page inside a named HyperBook, not merely as a raw browser URL.

Preferred form

The preferred conceptual link form is: 

<a hyperbook="fedwiki:wiki.ralfbarkow.ch" page="home-away-from-home">
  Home Away From Home
</a>

This is the right shape because it keeps three things explicit:

  • the owning site: fedwiki:wiki.ralfbarkow.ch
  • the page identity: home-away-from-home
  • the intention to stay inside the HyperBook and inspector model

The page slug is a better fit than a title-only reference because FedWiki link resolution is fundamentally site-plus-slug oriented.

Current limitation

This is the preferred model, but current HyperDoc page-link resolution may not yet support arbitrary fedwiki:... HyperBook ids in all HTML page contexts. So the conceptual form is correct even if the runtime support is not complete yet.

Fallback

If the HyperBook-style link does not resolve, use the explicit local server URL: 

<a href="http://127.0.0.1:8080/89661-wiki-ralfbarkow-ch/home-away-from-home">
  Home Away From Home
</a>

This is less satisfactory because it hardcodes the current local server URL and slug path, but it is operationally clear.

Why this matters

The page Home Away From Home is relevant when discussing alternative landing pages such as home/index.html. If HyperDoc can link to that FedWiki page through the HyperBook model, then the documentation remains inspectable and navigable inside the same environment instead of dropping to a plain external browser hop.
