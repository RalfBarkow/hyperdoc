Recent changes in a local Zotero library

hyperdoc

This slice adds a read-only recent-changes query for the local Zotero bridge. The entry point is (recent-zotero-changes &key bridge limit since include-attachments?). It returns a first-class zotero-recent-changes-query object whose rows are first-class zotero-recent-change-hit objects rather than a page-only summary.

Inspectable objects

  • Zotero recent changes query
  • Zotero recent change hit
  • (recent-zotero-changes :limit 10)
  • (recent-zotero-changes :limit 10 :since "2026-03-24")
  • (recent-zotero-changes :limit 10 :since "2026-03-24" :include-attachments? t)

Chosen signal

The first slice orders by the real Zotero column items.dateModified. That field is present on every row in the local items table, so it is a defensible cross-item ordering signal for a single recent-changes query.

The inspector makes that choice explicit. Query and hit views name the chosen field as items.dateModified instead of calling it a generic “last changed” timestamp.

Attachment rows may also carry storageModTime or lastProcessedModificationTime in itemAttachments. Those values remain visible in the raw row and hit overview, but this slice does not reinterpret them as the primary cross-item ordering field.

Parameters

  • bridge: optional explicit Zotero bridge; defaults to (make-default-zotero-library-bridge)
  • limit: maximum number of rows to keep in the first-class query object
  • since: optional string prefix or full SQLite timestamp compared against items.dateModified
  • include-attachments?: when true, attachment rows are included; notes and annotations stay out of this first slice

Inspector shape

The query object follows the same inspectable pattern as the existing Zotero title, item-id, and collection query objects. It exposes:

  • Overview: bridge, limit, since, selected attempt, and raw row count
  • Recent items: first-class hit rows with item identity, chosen timestamp field, chosen timestamp value, raw row, and evidence path
  • Grouped by day: the same hit objects grouped by the day prefix of the chosen timestamp
  • Raw SQL: the exact SQLite query text
  • Query evidence: selected attempt, attempt list, and selected rows
