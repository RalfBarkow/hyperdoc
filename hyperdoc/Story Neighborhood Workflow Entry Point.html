Story Neighborhood Workflow Entry Point

This page is a practical entry point into the Story Neighborhood Workflow narrative. The goal is not to flatten everything into one page. The goal is to make the topic traversable one idea at a time.

The representation pattern used here is simple:

  • one idea per section
  • one HyperDoc concept link per section
  • one localhost FedWiki page link per section when a concrete page exists
  • one note about missing pieces instead of pretending they already exist

The solution

Treat HyperDoc as the stable narrative spine and use it as the start page. Then attach concrete FedWiki pages and later Zettel references as secondary links under each idea. This keeps the entry point readable while still allowing the narrative to open into live material.

In short: 

HyperDoc idea page
  -> concrete localhost FedWiki page
  -> optional Zettel / note trail

The workflow mentions PRINT and REVIEW, but current localhost pages for those steps were not found under the expected slugs. This should be represented explicitly, not hidden.

That missingness is useful information. It tells you where the narrative still depends on verbal description instead of linked concrete pages.

8. Zettel as the fourth layer

Zettel should not replace the HyperDoc entry page. They should be attached as a fourth layer once a stable idea page and a stable concrete page already exist.

The intended order is: 

idea page -> live page -> implementation note -> Zettel

This keeps the start page readable and prevents the narrative from collapsing into a note dump.

Recommendation

Use this page as the start of the narrative. Extend it conservatively: whenever a new related topic appears, attach it under the single idea it clarifies instead of adding another undifferentiated related-links list.
