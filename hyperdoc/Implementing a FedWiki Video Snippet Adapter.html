Implementing a FedWiki Video Snippet Adapter

This page outlines the first implementation slice for handling FedWiki video snippets in HyperDoc.

Idea 1: add one adapter type only

Start with the FedWiki video item and only the form: 

YOUTUBE <video-id>
caption...

Do not generalize further until this path works.

Idea 2: parse into a small object

The adapter should parse the first line into provider and video id, and treat the remaining lines as caption text.

Idea 3: render two views

  • preferred: embedded player plus caption
  • fallback: external canonical link plus caption

Idea 4: make the conversion hook reusable

The implementation should create a reusable conversion boundary for FedWiki snippet types, not bury the logic directly inside one page renderer.

Idea 5: stop after the first working slice

The first goal is only to make one concrete page such as Video of Liquid Oxygen render the FedWiki video snippet meaningfully.
