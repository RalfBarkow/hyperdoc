Prepare hauptsache working tree for deployment

Confirm local branch state and deployment prerequisites before running checks or deployment.

Purpose

Avoid deploying from the wrong branch or from a tree that lacks required host outputs.

Prerequisites

  • Local clone of this repository.
  • Command-line access with Nix available.

Context

Deployment is driven from local flake state. Do not use server-side branch checkout as repair strategy.

Steps

  1. Confirm branch and working tree state: 
    git branch --show-current
git status --short
  2. Expect branch hauptsache and a clean tracked tree for production deployment.
  3. Confirm the deployment host output exists: 
    nix eval --raw .#nixosConfigurations.dreyeck-ch.config.networking.hostName
  4. Confirm the smoke-check app exists: 
    nix eval --raw .#apps.$(nix eval --raw --impure --expr builtins.currentSystem).release-smoke.program
  5. Confirm real host hardware config exists for deployment: 
    test -f nix/hosts/dreyeck-ch/hardware-configuration.nix

Result

  • If all checks pass, continue to local verification.
  • If any check fails, stop and port/apply the missing dreyeck-ch deployment profile in this local branch before deployment.
