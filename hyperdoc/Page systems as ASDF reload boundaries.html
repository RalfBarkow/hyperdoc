Obsolete migration note: Page systems as ASDF reload boundaries

hyperdoc

This page is obsolete. The former page-system registry, its descriptor files, and its ASDF naming convention were retired after the McDermott page-attached ASDF placement repair.

FedWiki page identity is no longer represented by HyperDoc-owned ASDF systems or by a HyperDoc default registry. A FedWiki page lives in the FedWiki pages store, and a page-attached ASDF entrypoint lives beside that page's assets under the FedWiki assets store.

  • FedWiki page JSON: /Users/rgb/.wiki/wiki.ralfbarkow.ch/pages/<slug>
  • FedWiki page-attached ASDF: /Users/rgb/.wiki/wiki.ralfbarkow.ch/assets/pages/<slug>/<slug>.asd
  • Generic HyperDoc support: make-fedwiki-attached-asdf-system and load-fedwiki-attached-asdf-system

Historical examples on this page used repo-local ASDF names for individual FedWiki pages and HyperDoc-authored page descriptors. Those examples are not current architecture and should not be copied into new code.

See FedWiki-attached ASDF system for the current contract.
