Selected ordered plan

  1. Establish the programming-style readability problem.
  2. Select a real program example.
  3. Read the program critically.
  4. Identify obscure expressions, confusing control flow, poor data representation, and missing validity boundary checks.
  5. Rewrite the program for clarity.
  6. Compare the original and the rewrite.
  7. Derive a style rule from the rewrite.
  8. Record the critical-reading lesson.
  9. Connect the base plan to Goldberg reader questions.
  10. Connect the base plan to Knuth WEB projections.
  11. Validate the plan artifact and implementation.
