Litlisp as experimental literate programming

hyperdoc

The McDermott software page includes Litlisp, a literate-programming system whose directives are Lisp commands but which can target other programming languages as well.

Inspectable objects

  • Litlisp
  • Literate programming
  • Documentation surface

Why it is interesting

The package is noteworthy not because it succeeded spectacularly but because the author leaves a strong warning right next to it: it is described as highly experimental and, on the whole, a failed experiment. That makes it valuable as a cautionary reference rather than a model to copy.

What to preserve

  • the idea that literate directives can themselves be Lisp commands
  • the decoupling between directive language and target implementation language
  • the explicit admission that publication does not equal endorsement

Why HyperDoc should care

HyperDoc is also concerned with documentation surfaces that remain close to code and runtime objects. Litlisp therefore belongs as adjacent history: not a direct ancestor, but a useful failed attempt in the same broad design territory.
