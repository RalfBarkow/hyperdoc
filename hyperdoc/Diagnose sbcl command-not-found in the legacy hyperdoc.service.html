Diagnose sbcl command-not-found in the legacy hyperdoc.service

Reproduce and explain why the legacy workspace unit exits with status 127.

Purpose

Verify the failure mode before replacing the old unit definition.

Prerequisites

  • Detect legacy workspace-checkout hyperdoc.service on dreyeck.ch confirms the legacy unit is active.

Context

Observed logs show: /home/rgb/workspace/hyperdoc/start.sh: line 24: sbcl: command not found.

Steps

  1. Inspect the launcher script used by the unit: 
    sudo -u rgb bash -lc 'cd /home/rgb/workspace/hyperdoc && sed -n "1,60p" start.sh'
  2. Run the same launcher manually as the service user: 
    sudo -u rgb bash -lc 'cd /home/rgb/workspace/hyperdoc && ./start.sh'
  3. Confirm that the script directly invokes sbcl and fails with command-not-found.

Result

  • status=127 means command not found.
  • In this case, the missing command is sbcl.
  • The legacy workspace unit PATH does not provide sbcl, so this unit cannot start as currently configured.
