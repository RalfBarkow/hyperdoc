Static Asset Path Resolution

hyperdoc

This page exposes first-class, inspectable path-resolution objects for the core static asset routes used by local HyperDoc and CLOG startup. The objects are based on static computation from the current server wiring. They do not perform live HTTP probes.

Inspectable objects

  • hyperdoc-static-asset-resolution-surface
  • hyperdoc-static-asset-resolution-surface comparison
  • /boot.html
  • /js/boot.js
  • /js/jquery.min.js
  • /hyperbook-server/js/url.js

Scope

  • Default CLOG static-root ownership for /boot.html, /js/boot.js, and /js/jquery.min.js
  • hyperbook-server runtime asset-mount ownership for /hyperbook-server/js/url.js
  • Filesystem resolution against the currently computed mounted roots
