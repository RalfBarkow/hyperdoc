Detect legacy workspace-checkout hyperdoc.service on dreyeck.ch

Determine whether dreyeck.ch is still running the old server-local workspace service model.

Inspectable objects

  • Legacy workspace-checkout hyperdoc.service
  • dreyeck supported deployment model

Purpose

Confirm whether the host is blocked on the legacy unit before attempting deployment.

Prerequisites

  • SSH access to dreyeck.ch.
  • Permissions to inspect systemd units and logs.

Context

The observed blocker is a legacy unit that launches HyperDoc from /home/rgb/workspace/hyperdoc/start.sh.

Steps

  1. Inspect the unit definition: 
    systemctl cat hyperdoc.service
  2. Inspect recent boot logs for the unit: 
    journalctl -u hyperdoc -b -n 100 --no-pager
  3. Check for legacy markers:
    • Description=HyperDoc (workspace checkout)
    • cd /home/rgb/workspace/hyperdoc && exec ./start.sh

Result

If hyperdoc.service still says “HyperDoc (workspace checkout)”, dreyeck.ch is still on the old deployment model, and that must be replaced before hauptsache can be deployed in the supported way.
