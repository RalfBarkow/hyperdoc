Goldberg reading comprehension questions

hyperdoc

Goldberg's four system layers become a twelve-question HyperDoc matrix. Each question is both a topic candidate and a clickable operation target.

Inspectable objects

  • Goldberg reading comprehension question
  • (goldberg-reader-question-matrix)
  • (goldberg-layer-overview :structure)

User-interface layer

  • 1. How do I invoke response?

Functionality layer

  • 2. What specifically can I do now?
  • 3. What is needed to do a specific function?

Structure layer

  • 4. What is that?
  • 5. Where is it?
  • 6. Does any part of the system do this?
  • 7. What part of the system knows about that?
  • 8. How did I get here? What has been happening?
  • 9. How can I get back?

Language / implementation layer

  • 10. What is the current state of the system?
  • 11. Why did that happen?
  • 12. Why didn't that happen?

HyperDoc interpretation

The questions should be answered by the system in the same place where the reader gets stuck: a selected token, a failed operation, a missing page, a stale topic, a hidden precondition, or an unclear route. The page therefore treats questions as runtime operations rather than only as prose headings.
