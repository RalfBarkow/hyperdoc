Time Machine Backup Setup

hyperdoc

This page provides the minimum operational path for getting a working macOS Time Machine backup to either a directly attached disk or an SMB-capable NAS target.

What Time Machine can back up to

  • Directly attached disk: external storage connected to the Mac.
  • Network target over SMB: a NAS or other network destination that supports Time Machine over SMB.

Apple documents that current macOS can use a third-party NAS that supports Time Machine over SMB, and that the Mac must be able to connect to the SMB server while you set up the backup.

Preconditions for a working backup target

  1. Make sure the target disk or NAS is powered on and reachable.
  2. If using a network target, open Finder -> Network and confirm the server appears.
  3. Open the target share and confirm you can authenticate successfully.
  4. Confirm the share is writable with the credentials you intend to use for Time Machine.
  5. For NAS use, confirm the server advertises or supports Time Machine over SMB.

A network destination that appears in System Settings but cannot be mounted in Finder is not ready for a reliable first backup.

Step-by-step setup on macOS

  1. Open System Settings -> General -> Time Machine.
  2. Click Add Backup Disk or + to select a destination.
  3. Select the directly attached disk or reachable SMB/NAS destination.
  4. If prompted, enter the username and password required for the network share.
  5. Decide whether to encrypt the backup before confirming the destination.
  6. Finish setup and wait for Time Machine to schedule or begin the first backup.

For an SMB/NAS target, the expected result is that the selected destination remains listed in Time Machine and the first backup begins preparing or transferring data instead of immediately stalling in a disconnected state.

Choosing encryption

If you need confidentiality for a network backup, enable encryption during setup. Apple documents encryption as the normal mechanism for protecting Time Machine backups on shared or network-attached storage.

What to expect from the first backup

  • The first backup can take much longer than later incremental backups.
  • Slow initial progress is not by itself a failure if bytes and estimated size continue changing.
  • No visible progress for an extended period is a troubleshooting case, not a normal success state.

Apple documents that the initial backup can take a long time, especially over the network.

What success looks like

  • The destination remains selected in System Settings -> General -> Time Machine.
  • Time Machine transitions from configuration to an actual running backup.
  • After completion, Time Machine shows a recent successful backup timestamp.
