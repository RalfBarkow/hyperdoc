Live parity evidence

Live parity evidence is the set of observations strong enough to support the claim that the live dreyeck service matches the intended localhost-scoped example surfaces.

Inspectable objects

  • Live parity evidence
  • Scoped example parity
  • Probe dreyeck runtime load set
  • dreyeck HTTP smoke probes

Evidence classes

  • HTTP/UI evidence: the site serves and the expected example scopes appear in the UI.
  • Runtime probe evidence: the running image reports loaded systems and nonempty scoped discovery.
  • Service/log evidence: the service restarted cleanly and did not need rescue loads.

Relative strength

Runtime probe evidence is the strongest confirmation of scoped example parity. HTTP/UI evidence is necessary but can be weaker if it is not paired with load-set evidence.
