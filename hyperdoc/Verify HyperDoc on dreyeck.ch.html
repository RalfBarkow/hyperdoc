Verify HyperDoc on dreyeck.ch

Run minimal post-deploy checks against the deployed service.

Purpose

Confirm that the service is reachable, key page routing works, and URL helper assets are served.

Prerequisites

  • Deploy dreyeck.ch from the local flake has completed.

Context

These checks are remote validation, not local build validation.

Steps

  1. Check boot page: 
    curl -I https://dreyeck.ch/boot.html
  2. Check one key HyperDoc page (official tutorial): 
    curl -I "https://dreyeck.ch/584FD-hyperdoc/Official%20Tutorial%3A%20NixOS%20SD%20Image%20on%20Raspberry%20Pi%204%2F400"
  3. Check URL helper asset: 
    curl -I https://dreyeck.ch/hyperbook-server/js/url.js

Result

  • All three checks return HTTP 200.
  • No broken relative-slug URL behavior is observed in the deployed page flow.

Rollback/next step

If checks fail, run Roll back HyperDoc on dreyeck.ch.
