Verify HyperDoc on dreyeck.ch

Run the minimal HTTP checks after test activation and again after switch.

Inspectable objects

  • dreyeck HTTP smoke probes
  • Deployment command locality
  • Cautious nixos-rebuild activation sequence

Purpose

Confirm route reachability and URL-helper asset availability before and after persistent activation.

Prerequisites

  • Deploy dreyeck.ch from the local flake reached the verification checkpoint.

Context

Run these commands on the local controller against the public URLs; they complement local flake/release verification.

Steps

  1. Check boot page: 
    curl -I https://dreyeck.ch/boot.html
  2. Check official tutorial page: 
    curl -I "https://dreyeck.ch/584FD-hyperdoc/Official%20Tutorial%3A%20NixOS%20SD%20Image%20on%20Raspberry%20Pi%204%2F400"
  3. Check URL helper asset: 
    curl -I https://dreyeck.ch/hyperbook-server/js/url.js

Result

All three probes return HTTP 200.

Rollback/next step

If checks fail, stop and run Roll back HyperDoc on dreyeck.ch.
