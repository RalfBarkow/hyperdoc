Make Alternate Source the Default Source View

HyperDoc text pages now split reading from source-line anchoring. The inspector tab titled Source is the readable plain file-content source view. The inspector tab titled Connect source is the connect-capable source-v1 view used for source-line anchors.

Contract

  • Source renders the plain readable source surface that the swap preview formerly exposed as Alternate Source.
  • Source does not expose data-hyperdoc-connect-provider-kind="source-v1" or other stale Connect provider metadata.
  • Connect source uses render-source-connect-surface and keeps the source-v1 provider path available for route-laying from source lines.
  • The strategy machinery remains first class: source-surface-strategy, plain-source-surface-strategy, connect-source-surface-strategy, source-surface-swap-preview, and source-surface-strategy-catalog.
  • The default and effective source-surface strategy for text pages is :plain. A swap preview from the default source path offers :connect as the alternate candidate.

Runtime Boundary

Source is for reading. Connect source is for source-line anchoring. The Dock/Connect workflow must therefore use the explicit Connect source surface when an operator wants to lay a route from source text. This preserves the readable default without removing the source-v1 provider path.

Inspectable Objects

  • Source readable view contract
  • Connect source view
  • Source surface strategy contract
  • Source pane layout evidence
  • (chunk-source-pane-layout-evidence)

Diagnostics

The Source surface diagnostic view should report Default strategy = plain (Plain source), Effective strategy = plain (Plain source), and Winner = default for ordinary text pages. The Source strategies view should still list both :plain and :connect, with only :connect marked connect-capable.

SLY mREPL Check

(require :asdf)
(asdf:load-system :hyperdoc/explorer)

(defun i (object)
  "Safe inspector helper for SLY mREPL.
Prefer CLOG only if it is already loaded; otherwise use CL:INSPECT.
Never calls SLYNK:INSPECT-IN-EMACS directly."
  (let* ((clog-package (find-package "CLOG-MOLDABLE-INSPECTOR"))
         (clog-symbol
           (and clog-package
                (find-symbol "CLOG-INSPECT" clog-package))))
    (if (and clog-symbol (fboundp clog-symbol))
        (funcall clog-symbol object)
        (cl:inspect object))))

(defparameter *source-contract-file*
  (merge-pathnames "hyperdoc-source-contract-mrepl.html"
                   (uiop:temporary-directory)))

(uiop:with-output-file (stream *source-contract-file*
                       :if-exists :supersede)
  (write-string "<h1>Source contract fixture</h1>
<p>Line anchor fixture.</p>
"
                stream))

(defparameter *source-contract-page*
  (make-instance 'hyperdoc::html-page
                 :id "source-contract-fixture"
                 :hyperbook (make-instance 'hyperbook:hyperbook :id "mrepl")
                 :file *source-contract-file*))

(defparameter *source-contract-report*
  (hyperdoc::source-surface-resolution-report-for *source-contract-page*))

(defparameter *source-contract-source-view*
  (hyperdoc::render-source-surface-for-page *source-contract-page*))

(defparameter *source-contract-connect-view*
  (hyperdoc::render-source-surface-for-page-with-designator
   *source-contract-page*
   :connect
   :title "Connect source"))

(format t "~&default=~A effective=~A source-view=~A connect-view=~A~%"
        (getf *source-contract-report* :default-strategy-id)
        (getf *source-contract-report* :effective-strategy-id)
        (type-of *source-contract-source-view*)
        (type-of *source-contract-connect-view*))

(i *source-contract-report*)
