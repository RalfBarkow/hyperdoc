SHOP3 page as ASDF system

hyperdoc

The FedWiki slug shop3 is represented by the ASDF page system fedwiki/page/wiki.ralfbarkow.ch/shop3. Loading this page system re-provides two runtime surfaces: the FedWiki display runtime needed to render and inspect the page, and the external SHOP3 Common Lisp runtime needed to inspect the HTN planner that the page names.

Runtime boundary

SHOP3 is an external open-source Lisp repository. HyperDoc integrates it as the flake input shop3 using github:shop-planner/shop3. The SHOP3 repository records several dependencies as git submodules, but one historical nested submodule cannot be fetched by Nix release builds without extra ref handling. HyperDoc therefore exposes the planner source plus the required Lisp dependency repositories as separate flake inputs: PDDL tools, fiveam-asdf, random-state, documentation-utils, trivial-indent, trivial-garbage, and iterate.

Local development can override the flake input with the adjacent checkout: 

nix develop --override-input shop3 path:/Users/rgb/workspace/shop3

The committed runtime code does not depend on that absolute path. It uses the flake input in normal dev/release mode and records the local path only as an operator override.

Reload

nix develop -c sbcl --noinform --disable-debugger \
  --eval '(require :asdf)' \
  --eval '(asdf:load-system :fedwiki/page/wiki.ralfbarkow.ch/shop3 :force t)' \
  --eval '(hyperdoc:find-page-system :fedwiki/page/wiki.ralfbarkow.ch/shop3)' \
  --eval '(quit)'

Loading this boundary makes :shop3, the SHOP3 package, and the SHOP3-USER package available through ASDF. It also loads the optional hyperdoc/shop3 planning layer so HyperDoc can inspect SHOP3-facing plan objects.

Display contract

  • The local FedWiki twin at /Users/rgb/.wiki/wiki.ralfbarkow.ch/pages/shop3 resolves without live network access.
  • The rendered page action resolves (hyperbook:find-hyperbook "fedwiki:wiki.ralfbarkow.ch") and (hyperbook:find-page * "shop3").
  • The story renderer runtime is provided by hyperbook/fedwiki.
  • The SHOP3 runtime is available through asdf:load-system :shop3.
  • SHOP3 source provenance is inspectable through the flake input or ASDF source directory.

Validation

nix develop -c sbcl --noinform --disable-debugger \
  --eval '(require :asdf)' \
  --eval '(asdf:load-system :hyperdoc/tests)' \
  --eval '(hyperdoc/tests:run-shop3-page-system-smoke-tests)' \
  --eval '(quit)'

Boundary

Loading the SHOP3 page system does not start a server and does not run a planning problem. It re-provides code, page descriptors, and inspector actions. Running examples, plans, or tests remains an explicit operation.
