Obsolete migration note: SHOP3 page as ASDF system

hyperdoc

This page is obsolete. It documented the retired page-system registry pattern in which a FedWiki page was mirrored by a repo-local ASDF name. That pattern is invalid for current HyperDoc/FedWiki work.

FedWiki pages now remain in the FedWiki pages store. If a page owns executable Lisp assets, its ASDF entrypoint belongs under the page-attached assets directory in the FedWiki assets store, not in HyperDoc's ASDF namespace.

SHOP3 itself remains a real external runtime. HyperDoc-owned SHOP3 support continues through the runtime and planning systems, not through a FedWiki page registry entry.
