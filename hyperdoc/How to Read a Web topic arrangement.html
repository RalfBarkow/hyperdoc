How to Read a Web topic arrangement

hyperdoc

The topic arrangement separates Knuth's operations from Goldberg's reader questions.

  • how-to-read-a-web — FedWiki page-attached ASDF system that demonstrates Knuth-style reader-order and machine-order projections.
  • cut-up-operation — Partition a program into small numbered sections that can be read locally.
  • rearrange-operation — Project the same sections into machine order by expanding unnamed roots, named replacement sections, and macros.
  • reader-order — The order in which a person should encounter motivation, vocabulary, mechanism, and evidence.
  • machine-root — Unnamed section that contributes directly to the tangled program before references are expanded.
  • named-replacement-section — A section that can be referenced by name and expanded into the machine projection.
  • appended-section — Repeated use of a named section adds more replacement text to the same logical section.
  • macro-replacement — Small-scale textual replacement used during tangling.
  • where-used-map — Backlink map from named sections to the sections that reference them.
  • woven-html — Reader-order HTML projection of the WEB-like source.
  • tangled-lisp — Machine-order Common Lisp projection of the WEB-like source.
  • function-coverage — Goldberg-style report indicating which Lisp functions exist and which are still missing for a full WEB clone.
