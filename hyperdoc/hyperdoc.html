HyperDoc

HyperDoc is a hypertext documentation module for computational systems.

Documentation consists of any combination of:

  • Text pages
  • Source code files
  • Data objects

All of these items can cross-reference each other.

If this is your fist contact with HyperDoc, you should start with:
  • Navigating a HyperDoc
If you are a HyperDoc author, the following pages are for you:
  • Creating a HyperDoc
  • Writing HyperDoc text pages
  • Writing HyperDoc source code pages
