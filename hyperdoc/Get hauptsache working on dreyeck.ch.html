Get hauptsache working on dreyeck.ch

Minimal operator procedure to deploy HyperDoc from a local hauptsache working tree to the NixOS host dreyeck.ch.

Purpose

Provide the shortest credible deployment path with clear checkpoints and rollback.

Prerequisites

  • SSH access to the target host.
  • Nix CLI and flake support on the controller machine.
  • Local repository checkout at branch hauptsache.

Context

hauptsache should be verified locally and deployed from the local flake; the server should not be repaired by checking out that branch directly.

Task sequence

  1. Prepare hauptsache working tree for deployment
  2. Verify HyperDoc locally before deployment
  3. Deploy dreyeck.ch from the local flake
  4. Verify HyperDoc on dreyeck.ch
  5. Roll back HyperDoc on dreyeck.ch

Result

You have a local-first deployment path with explicit prechecks, deployment command, remote checks, and rollback.
