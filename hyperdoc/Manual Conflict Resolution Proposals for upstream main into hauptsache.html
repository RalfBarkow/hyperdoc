Manual Conflict Resolution Proposals for upstream main into hauptsache

hyperdoc

This page turns the merge-driving conflict set into explicit proposed resolutions. The durable fact is a typed git-conflict-resolution-proposal object per covered path, not only a narrative about how the merge might go later.

Each proposal records the path, current branch roles, exact conflict shape, preferred merged form, result placement, and a minimal pseudo-diff that can drive the later hand-merge without executing it yet. The new follow-on layer is an execution recipe surface that turns those merged-form stances into path-by-path splice instructions and validation targets.

The page stays current-frontier-aware without flattening history. It still preserves the historical three-path dossier proposals, but it now also adds proposal coverage for the five promoted extra raw conflicts so the authoritative six-path frontier is fully proposal-backed and handoff-ready for execution recipes.

Views

  • 👀resolution-proposals on the proposal surface groups the current six-path frontier separately from the two historical dossier proposals that no longer remain raw.
  • 👀summary on a single proposal shows the branch roles, proposal source, merge action, what to keep from upstream, what to keep from hauptsache, the preferred merged form, and the patch sketch.
  • 👀execution-recipes on the execution-recipe surface is the next handoff: it turns the same six proposal-backed paths into explicit splice boundaries and post-splice validation targets.
  • 👀current-frontier on the current manual merge-driving frontier object links the same six blocking paths to both their proposal objects and their execution recipes and shows the zero-gap checks.

Why this is still pre-merge work

These are proposed merged forms, not applied patches. The point of this page is to make the later manual merge replayable and inspectable without running git merge yet. After this slice the remaining readiness block is recipe quality and later execution, not missing proposal objects or missing execution-recipe objects for the current frontier.
