Manual Conflict Resolution Proposals for upstream main into hauptsache

hyperdoc

This page turns the manual-conflict dossier into explicit proposed resolutions. The durable fact is a typed git-conflict-resolution-proposal for each manual path, not only a narrative about how the merge might go later.

Each proposal records the path, current branch roles, exact conflict shape, preferred merged form, result placement, and a minimal pseudo-diff that can drive the later hand-merge without executing it yet.
