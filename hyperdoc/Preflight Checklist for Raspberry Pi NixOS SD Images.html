Pre-flight Checklist for Raspberry Pi NixOS SD Images

hyperdoc

Run these checks before trusting a flashed SD image or before rebuilding the first generation on a Raspberry Pi 4 or Pi 400.

Commands

df -h /boot
ls -la /boot/extlinux
ls -la /boot/nixos
ls -la /dev/disk/by-label | grep -E 'FIRMWARE|NIXOS_SD' || true

Rules

  • If /boot is below 128MB, stop and re-image.
  • If /boot/extlinux is missing or truncated, reboot is unsafe.
  • If labels FIRMWARE and NIXOS_SD are missing, verify that this is really the SD-image model.
  • Prefer nixos-rebuild boot first, not switch.

Why These Checks Exist

They catch the most expensive class of early mistakes:

  • wrong image
  • wrong partition layout
  • too-small boot partition
  • extlinux already broken before reboot

How This Fits the Official Tutorial

The official tutorial assumes a valid preinstalled SD image. This checklist is the maintenance-story version of that assumption: verify the invariant before betting a reboot on it.
