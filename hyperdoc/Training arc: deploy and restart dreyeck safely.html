Sequence

  1. Verify locally before deployment
  2. Back up dreyeck
  3. Record the current generation
  4. Rehearse with the runner
  5. Deploy or restart dreyeck and confirm live parity
  6. Roll back if needed

What the operator should learn

The operator should learn that safe deployment is not one command but a sequence: local gate, target safeguards, rehearsal, activation, verification, and recovery.
