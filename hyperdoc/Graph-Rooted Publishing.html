Graph-Rooted Publishing

The phrase graph-rooted publishing means that the primary publishing object is not a single self-sufficient document. The primary object is a set of connected pages and the traversal rules that define which part of that page graph belongs to the current artifact.

Document-rooted publishing

In document-rooted publishing, one document is primary.

  • The document defines its own boundary.
  • Links are secondary references.
  • Publishing starts from render this document.
  • Scope is mostly defined by file or chapter boundaries.

In that model, links are useful, but they do not define the artifact.

Graph-rooted publishing

In graph-rooted publishing, the primary object is a connected page graph.

  • Seed pages define the entry points.
  • Traversal rules define the scope.
  • Links are part of the publishing structure.
  • Publishing starts from extract and materialize this neighborhood.

The artifact is therefore a projection of a graph, not merely a rendering of one document.

Why Story Neighborhood Workflow is graph-rooted

In the Story Neighborhood workflow, the story is not just an article to be rendered. It is a graph entry point.

  • The story defines the seed set.
  • WALK defines how far to traverse from that seed.
  • PRINT materializes the resulting connected subgraph.

So the publishing unit is not “this page alone” but “this neighborhood derived from the page graph”.

Why this matters editorially

  • Scope becomes explicit.
  • Boundary problems show up as graph problems, such as dangling references.
  • Repair work focuses on neighborhood structure, not only local page wording.
  • A book can be derived from relations among pages, not assembled manually from isolated files.

Compact contrast

document-rooted: page -> render
graph-rooted: seed pages -> traverse graph -> materialize result

This distinction matters because it changes what counts as the source of truth. In document-rooted publishing, the source of truth is the document. In graph-rooted publishing, the source of truth is the page graph plus the rules used to select a neighborhood from it.
