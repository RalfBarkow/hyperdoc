Hydra latest filename handoff defect

hyperdoc

This defect captures the relation between indirect Hydra latest-download URLs and decompression preconditions. Plain wget "$LATEST_URL" can produce file 1 instead of a named .img.zst artifact.

Inspectable objects

  • Hydra latest filename handoff defect
  • Filename handoff defect object
  • Filename handoff patch target object
  • Filename-preservation regression check

Patch

Preserve the redirected artifact filename in the download step: wget --trust-server-names "$LATEST_URL".

Mechanism: Hydra latest/download/1 redirects to a concrete artifact URL ending in nixos-image-sd-card-*.img.zst, and --trust-server-names makes wget use that redirected name.

Postcondition: local directory contains the new nixos-image-sd-card-*.img.zst file directly, without renaming file 1.
