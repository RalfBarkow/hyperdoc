State-machine run

hyperdoc

A State-machine run is one concrete traversal of a reusable machine. It keeps input, visited states, transition trace, evidence trace, current state, timing, and failure classification available for inspection.

Definition versus run

The machine definition says what transitions are admissible. The run records what actually happened, what evidence was observed, and where the traversal currently stands.
