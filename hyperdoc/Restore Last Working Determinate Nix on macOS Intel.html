Restore Last Working Determinate Nix on macOS Intel

hyperdoc

This page documents the bounded legacy fallback for Intel macOS hosts that still need to try the last plausible pre-drop Determinate installer line.

Boundary statement

This is not a supported current vendor path. It is a best-effort fallback derived from the release boundary: v3.13.0 drops x86_64-darwin, so v3.12.2 is only the last plausible pre-drop line to try on Intel macOS.

Use this only if all of these are true

  • The host is an Intel Mac and uname -m prints x86_64.
  • You understand that upstream Nix is still the primary recommendation.
  • You want a bounded recovery attempt, not a claim of restored vendor support.

Procedure

  1. Confirm the host architecture: 
    uname -m
  2. Remove an existing Determinate-managed install first if present: 
    if [ -x /nix/nix-installer ]; then
  sudo /nix/nix-installer uninstall
fi
  3. Try the pinned legacy installer line: 
    curl -fsSL https://install.determinate.systems/nix/tag/v3.12.2 | sh -s -- install --determinate
  4. Verify what landed: 
    file /usr/local/bin/determinate-nixd 2>/dev/null || true
nix --version 2>/dev/null || true

Wrong moves to avoid

  • Do not download nix-installer-aarch64-darwin on an Intel Mac.
  • Do not download nix-installer-x86_64-linux on an Intel Mac.
  • Do not present v3.12.2 as currently supported by Determinate.

If the pinned legacy line does not work cleanly, stop and use Reinstall Upstream Nix on macOS.
