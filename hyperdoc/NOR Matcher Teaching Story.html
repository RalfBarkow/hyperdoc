NOR Matcher Teaching Story

hyperdoc

This page is a teaching narration for the NOR-only matcher variant of the closure-compiled query matcher. It is meant to be used together with the SLY REPL: first predict the result, then run the example, then inspect the trace.

1. The one connective

In this teaching slice, the object language has only strings and nor forms. A string succeeds when it is found in the target text. A nor form succeeds only when all of its subforms fail. 

(nor "shuttle" "joke")

This means: accept only strings that contain neither “shuttle” nor “joke”.

2. Empty NOR

The empty NOR succeeds. This is the base case that lets a NOR form succeed after all of its subforms have failed.

nor-demo-empty-success

3. First positive example

Ask the learner to predict the result before pressing the play button. The target contains neither forbidden word, so the NOR should succeed.

4. First negative example

Now the target contains forbidden words. The NOR should fail as soon as one subform succeeds.

nor-demo-simple-failure

5. Why this is still compilation

The matcher is built before it is run. The builder walks the expression and returns a tree of closures. The resulting closure is then called with a target string.

nor-demo-make-matcher

6. The NOR-only version of the original query

The ordinary query was: 

(or (and "space" "mission")
    (and (or "moon" "lunar") "landing"))

The teaching version rewrites this into a NOR-only expression and stores it in *nor-demo-expression*. The learner does not have to like this notation at first. The point is that one connective is sufficient.

nor-demo-original-query-positive

7. Negative case for the full query

This target is unrelated to the original query, so the NOR-only spelling should reject it.

Teaching choreography

  1. Show (nor "shuttle" "joke") in the SLY REPL.
  2. Ask: “What must be absent for this to succeed?”
  3. Run nor-demo-simple-success from HyperDoc.
  4. Inspect the returned :trace.
  5. Run nor-demo-simple-failure.
  6. Point to the :nor-short-circuit event.
  7. Only then show the full NOR-only expression.
