Goldberg long recognized problem crosswalk

hyperdoc

Goldberg's Programmer as Reader does not replace the Kernighan/Plauger base cycle. It restates the old program-readability problem for exploratory programming environments, where the system itself must help readers ask and answer comprehension questions.

Crosswalk

  • Base problem: executable code can still be hard to read.
  • Goldberg restatement: the environment must support reading as well as writing.
  • Reader operation: make questions such as what is that, where is it, and why did that happen inspectable.
