Deployment locality model

The backbone remains Deployment command locality: controller-local commands, remote-host commands, and public verification are different classes of action.

Safe path first: rehearse before switch

The recommended path is: local verification, backup, generation recording, runner rehearsal, then deploy or restart, then parity verification.
