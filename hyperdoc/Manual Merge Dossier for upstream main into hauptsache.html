Manual Merge Dossier for upstream main into hauptsache

hyperdoc

This page turns the remaining manual-merge-needed paths into typed manual-conflict objects. The current dossier is intentionally small: one object for each of the three overlapping package or ASDF files that still need deliberate resolution.

Each git-manual-conflict records the path, branch roles, why the merge is still manual, the preferred resolution strategy, and whether the resulting merged file belongs in HyperDoc core or in dreyeck.

The follow-on slice is the proposal surface: it keeps the same three manual conflicts but adds explicit merged forms and pseudo-diffs that can drive the later hand-merge work without executing the merge yet.

  • 👀summary on a single git-manual-conflict shows the exact reason and preferred resolution for that path.
  • 👀resolution-proposals on the follow-on proposal surface lists the preferred merged forms and pseudo-diffs.

Why these remain manual

The three remaining manual conflicts are not arbitrary. They are the package and system-definition boundaries where export surfaces, dependency direction, and future extension seams must be curated explicitly rather than inferred from an automatic merge.
