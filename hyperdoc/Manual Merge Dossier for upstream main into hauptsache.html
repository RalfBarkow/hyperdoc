Manual Merge Dossier for upstream main into hauptsache

hyperdoc

This page turns the original pre-rehearsal manual-merge-needed overlap set into typed manual-conflict objects. The dossier remains intentionally small and historical: one object for each of the three package or ASDF boundary files that the earlier overlap pass marked as manual.

Each git-manual-conflict records the path, branch roles, why the merge is still manual, the preferred resolution strategy, and whether the resulting merged file belongs in HyperDoc core or in dreyeck.

The anchored rehearsal has since refined the active gate. Two of these three dossier paths no longer appear as raw merge-tree conflicts at the review tips, but they remain here so the earlier expectation and the still-useful boundary proposals stay inspectable.

The follow-on slice is still the proposal surface: it keeps the same three historical dossier paths as authored history, but it now also adds explicit proposal objects for the five promoted current-frontier conflicts. The newer five raw conflicts still live on the current manual merge-driving frontier instead of being silently rewritten into this older dossier. The current execution-recipe surface keeps the same distinction: one remaining dossier raw conflict still executes beside five promoted extra conflicts, not inside a rewritten historical dossier.

Views

  • 👀manual-conflicts on the dossier object lists all remaining manual paths with their preferred strategies.
  • 👀summary on a single git-manual-conflict shows the exact reason and preferred resolution for that path.
  • 👀resolution-proposals on the follow-on proposal surface lists the preferred merged forms and pseudo-diffs.
  • 👀execution-recipes on the execution-recipe surface shows how the one remaining dossier raw conflict is now executed beside five promoted extra conflicts.
  • 👀current-frontier on the current manual merge-driving frontier object shows which dossier items still remain raw today and which promoted extra conflicts now sit beside them.

Why these remain manual

The three dossier paths are not arbitrary. They are the package and system-definition boundaries where export surfaces, dependency direction, and future extension seams had to be curated explicitly rather than inferred from an automatic merge. The rehearsal now shows that only one of them still remains on the raw frontier, but all three still matter as durable authored boundary records.
