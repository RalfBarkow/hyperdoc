Existing preserved cluster

The repository already preserves the Drew import as a coherent cluster: the YTools/Lexiparse/Nisp/Nity/Opt/ Optop software line, the PDDL and Opt planning line, ontology translation, estimated-regression planning, autonomous process, and a bridge from Drew's work into running image coherence.

Boundary

The import should stay concept-and-software oriented. Publication titles become direct topics only when they introduce a reusable concept for HyperDoc. The clearest candidate is A framework for maintaining the coherence of a running Lisp. Most of the other papers belong as references inside pages rather than as one-topic-per-paper objects.

Apply the same rule to Mind and Mechanism. Keep the book title as a page-level bridge/source unless that exact title already exists as a topic. Its authoritative local-source path is the Zotero report documented on Resolve a local PDF from Zotero in HyperDoc, not a repo-global prose claim about a fixed file path. For this slice, check exact titles in hyperdoc/topics.lisp first, then aliases, near-duplicates, and broader existing topics, and only then add new factories. The only new exact-title topic additions justified here are Computationalism, Symbols and semantics, Informational meaning, and Intentionality.

Running image coherence must also stay distinct from Live image versus durable source: the former is about internal coherence of an evolving live system, while the latter is about which artifact remains authoritative for rebuilds.
