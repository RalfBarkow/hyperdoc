SIFT careers topic arrangement

hyperdoc

This arrangement page records how the pasted SIFT careers source is split into durable HyperDoc topics. It keeps organization, source page, roles, skill clusters, work environment, and eligibility boundary as separate handles so later pages can link only to the concept they need.

Arrangement rules

  • The pasted page becomes one source-station page: Smart Information Flow Technologies Careers.
  • The company topic and the careers-page topic stay separate; the first names the organization, the second names this specific source artifact.
  • Each advertised role becomes a topic because the source distinguishes qualifications, classification, and candidate level.
  • Skill clusters become topics only when they are reusable beyond this one page.
  • Eligibility and equal-opportunity statements remain boundary topics, not hidden footnotes.

Maintenance note

Because job postings are time-sensitive, a later update should verify the live SIFT site before changing role availability. This arrangement page is about the pasted source and the topic split, not about asserting that the openings remain current.
