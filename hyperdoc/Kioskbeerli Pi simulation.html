Kioskbeerli Pi simulation

This page documents the plan-first subsystem for simulating the Kioskbeerli Pi state without mutating the real Raspberry Pi. The ASDF system is :kioskbeerli/pi-simulation.

The simulation starts from the documented Den base-system milestone: the real Pi has runtime hostname myhostname, Den hostname kioskbeerli, and a flake output nixosConfigurations.kioskbeerli-pi. The simulation subsystem does not contact the Pi, run nixos-rebuild, boot a VM by default, create secrets, write DMX, or enable kiosk/Cage/Chromium on the real target.

Inspectable subsystem

(asdf:load-system :kioskbeerli/pi-simulation)

(defparameter *example-plan*
  (kioskbeerli/pi-simulation:make-pi-simulation-plan))

(defparameter *example-session*
  (kioskbeerli/pi-simulation:make-pi-simulation-session
   :plan *example-plan*))

(format t "~&~A~%mode=~S levels=~D tasks=~D next=~D~%"
        (type-of *example-session*)
        (kioskbeerli/pi-simulation:execution-mode-of *example-session*)
        (length (kioskbeerli/pi-simulation:levels-of *example-plan*))
        (length (kioskbeerli/pi-simulation:tasks-of *example-plan*))
        (length (kioskbeerli/pi-simulation:next-actions-of *example-session*)))

Fidelity levels

  • Level 0: ASDF/plan-only simulation.
  • Level 1: Nix flake evaluation simulation.
  • Level 2: VM derivation build simulation.
  • Level 3: optional VM/MicroVM boot smoke, skipped unless a Linux virtualization backend is configured.

Level 3 is not part of default checks. A VM boot is an explicit operator action after backend detection and is skipped cleanly by default.

Nix shape

The future Nix shape keeps the real and simulated targets separate: 

nixosConfigurations.kioskbeerli-pi       # real target
nixosConfigurations.kioskbeerli-pi-sim   # simulation target
checks.<system>.kioskbeerli-pi-sim-eval
checks.<system>.kioskbeerli-pi-sim-build

The subsystem currently records non-executing command specs for: 

nix flake show
nix eval .#nixosConfigurations.kioskbeerli-pi.config.networking.hostName
nix eval --raw --expr '(import ./nix/den/kioskbeerli.nix)."kioskbeerli-pi".hostName'
nix build .#nixosConfigurations.kioskbeerli-pi-sim.config.system.build.toplevel
nix build .#nixosConfigurations.kioskbeerli-pi-sim.config.system.build.vm

Make targets

These Make targets are plan-first wrappers. They load the ASDF subsystem and print plan or command-spec information. They do not contact the Pi, run nixos-rebuild, create secrets, write DMX, or boot a VM by default. 

make kioskbeerli-pi-sim-plan
make kioskbeerli-pi-sim-eval
make kioskbeerli-pi-sim-build
make kioskbeerli-pi-sim-run

make kioskbeerli-pi-sim-run reports skipped when no KIOSKBEERLI_PI_SIM_BACKEND is configured. It is not part of default make check.

Behavior contract

The SCXML artifact is kioskbeerli/pi-simulation/kioskbeerli-pi-simulation.scxml. Progress states include plan-created, den-baseline-loaded, sim-flake-generated, eval-planned, eval-passed, vm-build-planned, vm-built, boot-backend-detected, vm-booted, probes-passed, and complete.

Blocked states include blocked-no-linux-backend, blocked-no-kvm, blocked-cross-arch, blocked-secret-fixture, blocked-vm-build, and blocked-vm-boot.
