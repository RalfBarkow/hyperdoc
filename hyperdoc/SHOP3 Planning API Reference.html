Result object

hyperdoc-htn-plan-result

The result object stores the SHOP3 result without turning it into an executor. Its default execution mode is :plan-only.

Planner entry point

(hyperdoc/shop3:run-hyperdoc-asdf-refactor-plan-object)

Runs the built-in hyperdoc-asdf-refactor-001 SHOP3 problem and returns a hyperdoc-htn-plan-result.

Minimal REPL session

(asdf:load-system :hyperdoc/shop3)

(defparameter *plan*
  (hyperdoc/shop3:run-hyperdoc-asdf-refactor-plan-object))

(describe *plan*)

(hyperdoc/shop3:hyperdoc-plan-checklist *plan*)

(hyperdoc/shop3:hyperdoc-plan-summary *plan*)

Design rule

SHOP3 proposes ordered maintenance plans. HyperDoc makes those plans inspectable. Execution remains manual until a later guarded execution boundary is explicitly designed.
