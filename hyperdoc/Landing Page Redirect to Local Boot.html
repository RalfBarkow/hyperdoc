Landing Page Redirect to Local Boot

This page records one boundary clearly: a remote landing page may redirect the browser to local boot.html, but it must not try to act as the local boot page itself.

Idea 1: redirect is viable

A non-wiki landing page can send the browser to the local HyperDoc entry point. 

remote landing page
  -> http://127.0.0.1:8080/boot.html

Once the browser has navigated, the local page loads boot.js and starts the normal local CLOG session.

Idea 2: direct remote-to-local websocket boot is not viable

A remote page that stays on its public origin must not try to connect directly to ws://127.0.0.1:.../clog. That crosses the same browser boundary already seen in the bridge and private-network cases.

Idea 3: link the relevant FedWiki page in HyperBook form

The operational discussion belongs next to the FedWiki page that describes the custom landing-page pattern.

Home Away From Home

Idea 4: keep the fallback only as an operational note

If the HyperBook link does not resolve yet, the local server URL remains the operational fallback, but it should not replace the preferred representation. 

http://127.0.0.1:8080/89661-wiki-ralfbarkow-ch/home-away-from-home
