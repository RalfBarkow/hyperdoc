Page Lookup Rebuild Gate

hyperdoc

The page-lookup rebuild gate is the inspectable runtime check for the verify-no-page-lookup-issues state in the running-image coherence rebuild workflow.

It reloads HyperDoc text pages, scans authored local page links through HyperBook's exact lookup path, and returns an inspectable report object.

Inspectable report

  • Run page-lookup rebuild gate
  • Inspect page-lookup issues after rebuild

Boundary

This gate does not repair links automatically. Exact lookup is authoritative. Near-miss matching, including NOR-style candidate ranking, belongs to the diagnostic layer after a lookup issue exists. 

reload text pages
  -> scan authored local page links
  -> collect page-lookup issues
  -> inspect report
  -> repair authored page or link
  -> rebuild again

REPL use

(defparameter *page-lookup-rebuild-report* (make-page-lookup-rebuild-report)) (clog-moldable-inspector:clog-inspect :object *page-lookup-rebuild-report*)
