Fix Fish direnv Hook Error

hyperdoc

This page documents the small fish-shell cleanup for machines where direnv is not installed but the shell startup file still tries to source its hook.

Fish-shell fix

if command -sq direnv
    direnv hook fish | source
end

Where to put it

Put that guard around the existing direnv hook fish | source line in your fish startup file, typically ~/.config/fish/config.fish.

What this does and does not do

  • It removes shell-startup noise when direnv is absent.
  • It does not repair a broken Nix install.
  • It does not change the Intel macOS Determinate support boundary.

Treat this as shell hygiene after the install state is understood.

When direnv is no longer the blocker

Once type -a direnv, direnv --version, and the nix-direnv direnvrc check all pass, a failing direnv reload should no longer be documented as a direnv installation problem. In the observed recovery, direnv was functioning correctly and merely surfaced a failing flake dependency build.

The user-level direnv integration issue was resolved by installing nix-direnv, writing ~/.config/direnv/direnvrc to source ~/.nix-profile/share/nix-direnv/direnvrc, and restarting Fish. After that point, any remaining failure belonged to the project flake, not to missing direnv integration.

Inspect the flake failure directly

nix-store -l /nix/store/fwgh4qwhilxnx00vn8qsbzz7sdg9rhh6-clog-src-patched.drv
rg -n "clog-src-patched|clog-boot-ignore-empty-ids.patch|patches =" .

The environment manager is healthy. The broken unit is the project derivation clog-src-patched, specifically its patchPhase. The next debugging step is to inspect the derivation log and the flake expression that defines the patch input.

A patchPhase failure that stops immediately after “applying patch ...” with patch: **** out of memory is narrower than a generic build failure. In the observed case, unpacking completed and the derivation died before any patching file ... output appeared. That points first to a patch parser or patch-tool edge case at the handoff boundary, not yet to downstream compilation and not to an ordinary hunk-mismatch report.
