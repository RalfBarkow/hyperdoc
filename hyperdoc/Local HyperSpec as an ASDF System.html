Local HyperSpec as an ASDF System

The official LispWorks documentation page links to a downloadable archive of the Common Lisp HyperSpec. A local HyperDoc integration should keep that archive complete and unmodified, wrap it in a tiny ASDF system, and serve it from the same origin as HyperDoc. related

Recommended layout

my-project/
  hyperdoc-clhs.asd
  hyperdoc-clhs/
    package.lisp
    main.lisp
  vendor/
    HyperSpec-7-0/
      HyperSpec/
        Front/
        Body/
        Data/
        Issues/
        ...

ASDF system

(defsystem #:hyperdoc/clhs
  :description "Local Common Lisp HyperSpec mount for HyperDoc"
  :depends-on (#:asdf #:uiop)
  :serial t
  :components ((:file "hyperdoc-clhs/package")
               (:file "hyperdoc-clhs/main")))

Package

(defpackage #:hyperdoc/clhs
  (:use #:cl)
  (:export
   #:*mount-path*
   #:root-directory
   #:root-url
   #:local-url))

Main

(in-package #:hyperdoc/clhs)

(defparameter *mount-path* "/hyperspec/")

(defun root-directory ()
  (merge-pathnames #P"vendor/HyperSpec-7-0/HyperSpec/"
                   (asdf:system-source-directory :hyperdoc/clhs)))

(defun root-url (&optional (mount-path *mount-path*))
  mount-path)

(defun local-url (relative-path &optional (mount-path *mount-path*))
  (format nil "~A~A"
          mount-path
          (string-left-trim "/" relative-path)))

Operational rule

Keep the HyperSpec tree unmodified. Add HyperDoc controls, annotations, and provenance outside the copied files.
