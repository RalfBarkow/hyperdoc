How to merge proposed topic additions into hyperdoc/topics.lisp

Use exact topic title as the merge key.

That is the correct rule in the current Topics model because authored topic links resolve through a Topics HyperBook page title, and topic pages are rebuilt from topic-constructor functions and then registered by title. The real collision domain is duplicate :title values, not duplicate Lisp function names.

Merge rule

  1. For each proposed topic, search hyperdoc/topics.lisp for the exact :title string.
  2. If that title already exists, edit the existing factory in place.
  3. If that title does not exist, add a new ...-topic factory.
  4. Keep the existing canonical title stable unless you are intentionally doing a link migration, because title changes break authored page= targets until those links are updated.

What to merge when the title already exists

  • Usually keep the existing :id.
  • Usually keep the existing :title.
  • Tighten or broaden :summary only if the concept itself really changed.
  • Append new page titles to :references only when they actually belong to that topic.

Do not add a second topic factory with a different Lisp function name but the same :title. That creates a duplicate title collision in the topic-page layer.

Applied to the Drew McDermott slice

  • Drew McDermott is likely a new topic, so add a new factory if that exact title does not already exist.
  • PDDL may already exist. If it does, merge into the existing PDDL topic instead of creating another one.
  • Apply the same rule to reusable concepts such as Ontology translation or Autonomous process.

Practical workflow

  1. Open the proposed snippet.
  2. For each proposed :title, grep or search hyperdoc/topics.lisp.
  3. Reuse the existing topic function when the title already exists.
  4. Add only truly new titles as new topic factories.
  5. Reload :hyperdoc or the relevant system.
  6. Verify that the topic resolves by title.

Minimal verification

(asdf:load-system :hyperdoc/explorer)

(fboundp 'hyperdoc::drew-mcdermott-topic)
(hyperbook:find-page hyperdoc::*topics* "Drew McDermott" :signal-error? t)

Durable rule: deduplicate by exact :title; reuse and edit the existing factory when the title already exists; add a new factory only for titles that do not yet exist.
