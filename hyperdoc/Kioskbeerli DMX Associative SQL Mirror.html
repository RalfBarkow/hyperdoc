Kioskbeerli DMX Associative SQL Mirror

This page records the committed Kioskbeerli path from an inspectable project trace to a DMX-shaped local SQLite mirror and then to a HyperDoc topicmap projection. The mirror is local evidence storage. It is not live DMX or Neo4j synchronization.

Current implementation

  • kioskbeerli/dmx-associative-mirror.lisp persists trace entries into DMX-shaped SQL tables.
  • kioskbeerli/dmx-sql-topicmap.lisp parses the SQL mirror into projection nodes and edges.
  • kioskbeerli/dmx-sql-topicmap-hyperdoc.lisp adapts the projection to HyperDoc's topicmap inspector model.
  • tests/kioskbeerli-dmx-associative-mirror-smoke.lisp is the narrow standalone mirror smoke test.

Accepted evidence

The persisted mirror evidence currently accepted for this slice is:

  • The local SQLite database contains a DMX-shaped mirror, not a flat event log.
  • The persisted trace contains 7 trace-event topics.
  • The persisted trace contains 14 provenance associations.
  • The topicmap projection contains 33 nodes and 49 edges.
  • The projection title is Kioskbeerli persisted DMX SQL topicmap.
  • Inspecting the projection opens the HyperDoc/DM6 Topicmap view.
  • The visible graph includes state, status, provenance, and topic nodes.
  • The old pathname/content-chunk fallback is no longer the observed inspector path.

SQL model

dmx_sql_object
  common identity for topics and assocs

dmx_sql_topic
  topic-shaped objects

dmx_sql_assoc
  association-shaped objects

dmx_sql_assoc_player
  role-bearing players of associations

dmx_sql_property
  extensible properties / occurrence-like values

dmx_sql_sync_identity
  correspondence between SQL local object and a DMX host identity

dmx_sql_sync_journal
  observed reads, staged writes, sync decisions, and conflicts

Identity invariant

DMX numeric ids are host-local. The SQL mirror therefore records remote ids only inside dmx_sql_sync_identity. Durable cross-host identity uses stable URIs such as dmx://dreyeck/topic/982950 or local mirror URIs such as hyperdoc:kioskbeerli/trace-event/trace-ssh-copy-id-verified.

MREPL inspection

These forms inspect an existing local SQLite mirror. They do not write to DMX, Neo4j, Nix, or the Raspberry Pi. 

(require :asdf)
(asdf:load-system :kioskbeerli)

(defparameter *dmx-assoc-db*
  (asdf:system-relative-pathname
   :hyperdoc
   "var/dmx-associative-mirror.sqlite"))

(kioskbeerli.dmx-associative-mirror:dmx-sql-counts
 :db-path *dmx-assoc-db*)

(kioskbeerli.dmx-associative-mirror:dmx-sql-trace-events
 :db-path *dmx-assoc-db*)

(kioskbeerli.dmx-associative-mirror:dmx-sql-provenance-associations
 :db-path *dmx-assoc-db*)

Topicmap projection

The projection layer reads the DMX-shaped SQL mirror and constructs stable node and edge objects. The HyperDoc adapter then turns that projection into the native topicmap representation rendered by the DM6/AppEmbed inspector island. 

(defparameter *kb-dmx-sql-topicmap*
  (kioskbeerli.dmx-sql-topicmap:make-dmx-sql-topicmap-projection
   :db-path *dmx-assoc-db*
   :title "Kioskbeerli persisted DMX SQL topicmap"))

(kioskbeerli.dmx-sql-topicmap:projection-summary
 *kb-dmx-sql-topicmap*)

(kioskbeerli.dmx-sql-topicmap:projection-topicmap-payload
 *kb-dmx-sql-topicmap*)

(i *kb-dmx-sql-topicmap*)

Local persistence boundary

The mirror writer persists into the local SQLite file only. The generated database under var/ is intentionally untracked. Rebuilding it is a local evidence operation, not a DMX write and not a deployment action. 

;; Writes only the local SQLite mirror named by *dmx-assoc-db*.
;; Do not use this when only read-only inspection is intended.
(kioskbeerli.dmx-associative-mirror:persist-kioskbeerli-trace-as-dmx-sql
 (kioskbeerli:make-demo-trace)
 :db-path *dmx-assoc-db*)

Boundary

  • This page documents the local mirror and projection that are committed in source.
  • It does not claim live DMX or Neo4j synchronization.
  • It does not run nixos-rebuild.
  • It does not activate a flake or mutate the Pi.
  • Generated SQLite databases, WAL/SHM files, and trace dumps remain untracked runtime artifacts.
