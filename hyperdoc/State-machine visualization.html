State-machine visualization

hyperdoc

State-machine visualization names the derived graph, timeline, and matrix renderings that come from the machine object itself. The page does not hard-code one prose diagram; it points to runtime objects whose views produce the visualization from data.

The rendered Graphviz view is derived from DOT computed from the machine object. HyperDoc keeps the machine definition as the canonical source and keeps the older Directed graph text view as a teaching-oriented companion.

Visualization kinds

  • Graphviz: browser-rendered SVG derived from DOT computed from the machine definition.
  • Directed graph: preformatted teaching view of ordered states and outgoing transitions.
  • Timeline: emphasizes what happened in one concrete run.
  • Transition matrix: shows permitted, forbidden, and guarded source-to-destination pairs.
