Expectation preserved

The reasonable expectation was that reconcile=true would remain a read surface. Observed reality was different: the healthy handover topic 923609 resolved and read correctly, but reconcile-time handling still write-touched companion journal note 924694 and triggered backend 500s. That is a disappointed expectation case, not a false one, because the exposed surface was a read tool.

What the live view shows

  • The active reconcile-on-read path for read_workspace_journal and read_topic_journal.
  • The exact edge where synthesized diff events now stay in memory only.
  • The explicit write paths that still legitimately use the append and persist helpers.
  • The concrete live anchors: topicmap 919822, assoc 923622, healthy note topic 923609, and companion journal note 924694.

Why this boundary matters

The workspace journal model is allowed to infer synthesized-from-diff events because no authoritative DMX revision feed is proven. But inference during a read must not collapse into mutation. Otherwise the read path becomes able to mutate or reattach the hidden companion journal notes it is trying to inspect.
