Fedwiki Java Lisp Examples

hyperdoc

These examples translate small but important pieces of the fedwiki-java reference implementation into runnable HyperDoc Lisp examples.

The goal is not to reproduce the whole interpreter. The goal is to make the core semantics inspectable in HyperDoc terms.

Slug derivation

The Java reference implementation derives a slug from collaborative link text. This example shows the corresponding Lisp translation.

fedwiki-java-slug-example

Journal-derived context

The page context comes from journal site entries, read backward with duplicates removed. This example shows that logic directly.

fedwiki-java-context-example

Resolution order

Collaborative-link resolution tries the origin site first, then the current item site if present, then the remaining context sites in order. This example makes that search order explicit.

fedwiki-java-resolution-order-example
