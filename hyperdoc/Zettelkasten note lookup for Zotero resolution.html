Zettelkasten note lookup for Zotero resolution

hyperdoc

Note lookup is optional supporting evidence for Zotero resolution, not a full note-system importer. When note roots are configured, HyperDoc scans text notes for a narrow clue set and records the matches as inspectable note evidence objects.

Inspectable objects

  • Zotero library
  • Zotero attachment
  • (mind-and-mechanism-zotero-title-query)
  • (mind-and-mechanism-zotero-item-id-query)
  • (mind-and-mechanism-zotero-resolution-report)

Supported clues

  • exact title
  • DOI
  • Zotero item key
  • Better BibTeX citekey
  • attachment filename

The report records which note file matched which clue on which line. This keeps the evidence chain inspectable without turning the slice into a generic importer for arbitrary note formats.

In this slice, note evidence can narrow or explain both title lookup and the deterministic item-id verification path, but it never overrides Zotero's own item and attachment identities.

Current limit

Note evidence can support interpretation and later disambiguation work, but this first slice does not yet promote note hits into an automatic winner when the Zotero title or attachment space is ambiguous.
