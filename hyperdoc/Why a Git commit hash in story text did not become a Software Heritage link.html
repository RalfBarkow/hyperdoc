Why a Git commit hash in story text did not become a Software Heritage link

hyperdoc

Use this troubleshooting page when a piece of story text looks commit-like but did not turn into a Software Heritage revision link.

Common causes

Short hash instead of full hash

The supported contract in this path is a full 40-character Git commit hash. Short hashes are useful for humans but are not the renderer trigger here.

Unsupported text shape

The commit-linkification path and the ordinary external-link path are related but not identical. If you are also expecting a normal external URL to appear, verify that you are using the supported ordinary-link syntax in this path.

Wrong expectation about unrelated URL extraction behavior

A bare URL can look link-like to a reader, but that does not automatically mean this exact extraction path treats it as an ordinary external link. Check the nearby smoke tests and examples for the supported text form.

Wrong rendering path

Make sure you are actually testing the FedWiki story-item rendering path rather than another text-processing path in the system.
