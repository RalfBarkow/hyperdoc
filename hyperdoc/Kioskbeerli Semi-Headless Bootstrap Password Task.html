Kioskbeerli Semi-Headless Bootstrap Password Task

hyperdoc

This page exposes the DITA-style task topic for the one-time semi-headless bootstrap step where SSH asks for a password for nixos@<PI-IP-ADDRESS>, but no password is known yet.

Inspectable object

  • (kioskbeerli:kioskbeerli-semi-headless-set-password-task)
  • (kioskbeerli:kioskbeerli-task-topic-dita-view (kioskbeerli:kioskbeerli-semi-headless-set-password-task))

Current operational boundary

  • boot-pi is verified.
  • The password-bootstrap DITA task is active.
  • verify-network remains missing-evidence until SSH login succeeds.
  • verify-kiosk-session and verify-landing-page remain missing-evidence.

CL-USER / SLY usage

(require :asdf)
(asdf:load-system :hyperdoc/server)
(asdf:load-system :kioskbeerli)

(defparameter *task*
  (kioskbeerli:kioskbeerli-semi-headless-set-password-task))

(clog-moldable-inspector:clog-inspect
 :object *task*)

(kioskbeerli:kioskbeerli-task-topic-dita-view *task*)
(kioskbeerli:kioskbeerli-task-topic-plan-task *task*)
(kioskbeerli:kioskbeerli-task-topic-progress *task*)
(kioskbeerli:kioskbeerli-task-topic-state-link *task*)
