Why run this test

This focused smoke test checks the DMX topic proxy path directly. It covers the mapped DMX wrapper functions, the topicmap designator helper, the current /core/topic/<id> endpoint regression boundary, and the unknown-wrapper condition. It is useful when you want a narrow terminal check for the DMX proxy slice without invoking the whole HyperDoc test suite.

Exact command

nix develop --command sbcl --no-userinit --non-interactive \
  --eval '(require :asdf)' \
  --eval '(asdf:load-system :hyperdoc/tests :force t)' \
  --eval '(hyperdoc/tests:run-dmx-topic-proxy-smoke-tests)' \
  --eval '(uiop:quit 0)'

Step-by-step explanation

  1. nix develop --command sbcl enters the project development environment and runs SBCL in one shot.
  2. --no-userinit --non-interactive avoids user-local init noise and keeps the run non-interactive.
  3. (require :asdf) ensures ASDF is available.
  4. (asdf:load-system :hyperdoc/tests :force t) loads the HyperDoc test system and recompiles or reloads as needed.
  5. (hyperdoc/tests:run-dmx-topic-proxy-smoke-tests) runs only the DMX topic proxy smoke tests.
  6. (uiop:quit 0) exits cleanly on success.

Reading the output

The decisive success signal is the final smoke-test pass line: 

DMX topic proxy smoke tests passed (4 wrappers + topicmap helper + endpoint regression + unknown-wrapper condition).

The load phase can print warnings from ASDF, SBCL, dependency compilation, FTYPE proclamations, or redefinitions. Those messages are not by themselves the smoke-test verdict. For this focused procedure, failure means that the run signals an error or that the final DMX smoke-test pass line does not appear.

Focused runner versus full suite

This page documents a direct focused runner:

(hyperdoc/tests:run-dmx-topic-proxy-smoke-tests)

The broader umbrella suite uses:

(asdf:test-system :hyperdoc/tests)

The difference is simple: asdf:test-system delegates to the test system and runs the full configured suite, while hyperdoc/tests:run-dmx-topic-proxy-smoke-tests directly runs only the DMX topic proxy smoke-test function.
