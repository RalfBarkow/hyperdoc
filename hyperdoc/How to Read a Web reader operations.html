How to Read a Web reader operations

hyperdoc

Each operation is meant to answer a Goldberg-style comprehension question.

  • WHAT-IS-THIS: What object am I looking at?
    HOW-TO-READ-A-WEB-SUMMARY
  • WHY-IS-IT-HERE: Why is this object here?
    CUT-UP-AND-REARRANGE-REPORT
  • WHAT-CAN-I-DO: What actions are available?
    WEB-CAPABILITY-REPORT
  • WHAT-MUST-BE-TRUE: What preconditions are required?
    EXISTING-HYPERDOC-FUNCTION-PROBE
  • WHERE-IS-THE-DEFINITION: Where is a concept defined?
    WHERE-USED-MAP
  • WHERE-IS-IT-USED: Where is this section used?
    WHERE-USED-MAP
  • WHAT-IS-THE-MACHINE-VIEW: What will the computer see?
    TANGLE-WEB
  • WHAT-IS-THE-READER-VIEW: What will the reader see?
    WEAVE-WEB-HTML
  • WHAT-IS-MISSING: What is missing for a full WEB clone?
    WEB-CAPABILITY-REPORT
  • HOW-DID-WE-GET-HERE: What path produced this result?
    CUT-UP-AND-REARRANGE-REPORT
  • CAN-I-RECREATE-IT: Can I recreate the page/system?
    MATERIALIZE-HOW-TO-READ-A-WEB-BUNDLE
  • IS-EXISTING-HYPERDOC-ENOUGH: Do existing HyperDoc functions already cover this?
    EXISTING-HYPERDOC-FUNCTION-PROBE
