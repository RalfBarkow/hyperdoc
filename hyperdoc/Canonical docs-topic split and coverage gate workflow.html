Canonical docs-topic split and coverage gate workflow

hyperdoc

This maintenance page records the canonical way to split a mixed documentation patch into atomic commits and replay verification at explicit boundaries.

Inspectable objects

  • Docs/topic slice and coverage-gate workflow
  • Reconstruction protocol
  • Skillization loop

Purpose

Keep docs/topic history replayable and cherry-pickable by separating infrastructure, executable behavior, content/topic wiring, checks, and local hygiene.

Canonical commit stack

  1. feat(nixos): add dreyeck host hardware configuration baseline
  2. feat(deploy): add dreyeck cautious deployment runner
  3. docs(topics): add nixos-rebuild topic coverage to SD-image workflow pages
  4. test(docs): add topic coverage gate for hyperdoc expr references
  5. docs(topics): add inspectable topic coverage for dreyeck deployment workflow
  6. chore(gitignore): ignore local release and deploy artifacts

Boundary replay checks

  1. After deploy runner commit: 
    nix develop --command sbcl --no-userinit --non-interactive \
  --eval '(require :asdf)' \
  --eval '(asdf:load-system :hyperdoc :force t)' \
  --eval '(format t "HYPERDOC_LOAD_OK~%")' \
  --eval '(uiop:quit 0)'
  2. After topic coverage gate commit (default cluster): 
    nix develop --command sbcl --no-userinit --non-interactive \
  --load tools/check-topic-coverage.lisp
  3. After dreyeck docs/topic commit (explicit cluster): 
    nix develop --command sbcl --no-userinit --non-interactive \
  --load tools/check-topic-coverage.lisp -- \
  "hyperdoc/Get hauptsache working on dreyeck.ch.html" \
  "hyperdoc/Detect legacy workspace-checkout hyperdoc.service on dreyeck.ch.html" \
  "hyperdoc/Diagnose sbcl command-not-found in the legacy hyperdoc.service.html" \
  "hyperdoc/Locate and replace the legacy workspace hyperdoc.service definition.html" \
  "hyperdoc/Back up dreyeck.ch before deployment.html" \
  "hyperdoc/Record dreyeck.ch generation before rebuild.html" \
  "hyperdoc/Verify HyperDoc locally before deployment.html" \
  "hyperdoc/Rehearse dreyeck.ch deployment with runner.html" \
  "hyperdoc/Deploy dreyeck.ch from the local flake.html" \
  "hyperdoc/Verify HyperDoc on dreyeck.ch.html" \
  "hyperdoc/Roll back HyperDoc on dreyeck.ch.html"

Operational rule

Do not commit one catch-all patch for mixed docs/topic/deploy work. Split by ownership boundary and verify at each boundary.
