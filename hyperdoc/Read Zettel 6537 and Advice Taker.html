Contract

The first move is the plan artifact and explicit task-topic cluster. The reader implementation is downstream from that artifact: it may read local source surfaces, but it must not rewrite Zettel, FedWiki, or Advice Taker source content while establishing the reader boundary.

  • read-zettel-6537-and-advice-taker is the stable plan/topic id.
  • implement-zettel-6537-zettelkasten-file-reader is the follow-up plan/topic id.
  • read-zettel-6537-task is the task topic for the Zettel source station.
  • zettel-6537 has authoritative source zettel-6537-zettelkasten-file-source.
  • zettel-6537 has projection zettel-6537-fedwiki-projection.
  • physics-not-advice-source-station contextualizes zettel-6537.
  • zettel-6537-source-station, physics-not-advice-source-station, and advice-taker-source-station remain source-station handles.
  • materialize-source-reader-task-topics records the task-topic cluster in the Dreyeck DMX SQLite mirror.

Reader surfaces

The implemented reader surfaces are local-only and evidence-preserving: read-zettel-6537-zettelkasten-source reads the authoritative Zettel text from configured Zettelkasten roots, read-zettel-6537-source extracts FedWiki projection/context evidence from the local physics-not-advice page, read-physics-not-advice-source reads the local FedWiki page JSON, and read-advice-taker-source reads the local FedWiki page plus Advice Taker ASDF asset. Each result carries source identity, provenance, extracted fragments, derived topics, failure state, and :network-required-p nil.

The production Zettelkasten reader uses the existing HYPERDOC_ZETTELKASTEN_ROOTS convention. Tests pass an explicit :roots or :zettelkasten-roots fixture override, so validation does not require a private local Zettelkasten directory.

The Advice Taker reader treats a missing transcript as a partial source state, not an unhandled error. It preserves the page and topicmap summaries and records :reason :transcript-missing when the transcript text is absent.

Boundary

  • No network, DMX server, browser, or device is required.
  • The default Zettelkasten reader may use HYPERDOC_ZETTELKASTEN_ROOTS; deterministic tests must use fixture roots.
  • No Zettel or FedWiki reader writes source content in this slice.
  • No full Kioskbeerli load is required.
  • The SHOP3 fields are durable plan data; they are not proof that a planner runtime is coherent for this slice.
