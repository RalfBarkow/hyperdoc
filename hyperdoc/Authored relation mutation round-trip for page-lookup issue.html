Expected result

One bounded authored mutation changes the repo-native source relation, then reconstruction and compilation produce a visible consumer layout change without widening into a general editor.

Why this matters

This turns authored-relation-artifacts from read-only inspection into a controlled write-side loop that is still explicit, replayable, and bounded.

Boundary

  • One narrow mutation path on one consumer.
  • One explicit write target in repo-native source format.
  • Reconstruction/recompile loop remains separate and inspectable.
  • No full graph editor, no DMX/MCP write widening, no free-form mutation surface.
