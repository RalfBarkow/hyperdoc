Inspectable iconic retrieval objects

hyperdoc

This page exposes the narrow operational object model by which HyperDoc assimilates Aleksander & Morton 1993. HyperDoc keeps the local route language primary: a cue starts a route, a world-state proxy anchors a grounded station, an iconic state is the inspectable representation retrieved, and a trajectory preserves semantic path information. The NSMM object formalizes that layer, but does not replace it.

Operational reading

  • World-state proxy: inspectable stand-in for the grounded state or event pattern that matters to retrieval.
  • Iconic state: grounded representation acquired from a world-state proxy rather than from arbitrary label assignment alone.
  • Linguistic retrieval cue: symbolic trigger that starts the retrieval route without collapsing into the grounded state it retrieves.
  • Iconic retrieval route: first-class relation by which a cue retrieves a grounded/iconic state and its trajectory.
  • Iconic state trajectory: semantic path through iconic structure that preserves distinctions such as case-role readings.
  • NSMM: support object that keeps perceptual input, internal iconic state, early processing, and motor/action output legible as one general state-machine-like arrangement.

Paper-backed patterns

The lexical example preserves the paper's cup/image/phoneme/written-word pattern as a multimodal association that ends in a reentrant iconic state. The point is not that HyperDoc simulates neurons. The point is that the learned sequence can be inspected as a grounded state, a set of cues, a route, a trajectory, and a motor-action note.

The case-role example preserves the paper's rock-versus-curtain distinction by giving the two sentences different trajectories through iconic state structure. The semantic difference therefore lives in path structure, not in flat label attachment after the fact.

Together these examples support the local HyperDoc reading that symbolic triggering and grounded retrieval can stay integrated in one inspectable object model.
