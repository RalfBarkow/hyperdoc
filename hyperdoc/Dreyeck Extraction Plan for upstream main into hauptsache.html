Dreyeck Extraction Plan for upstream main into hauptsache

hyperdoc

This page turns the current clearly-dreyeck-candidate path set into a typed extraction plan. The durable object is a git-dreyeck-extraction-plan, not only a paragraph about future cleanup.

The current plan groups the 44 candidate paths into four buckets:

  • runtime-hooks
  • local-deployment
  • page-content-overlays
  • glue-code

For each bucket, the object graph records the concrete path list, why those paths do not belong in upstream core, the expected ASDF placement or downstream layer, the dependency direction, and whether the local behavior should move, wrap, or become a hook/protocol seam.

The follow-on slice is the transition plan: it keeps the same buckets but adds concrete target destinations, core continuation points, and validation proofs for the future split.
