DITA-like task topics for LISP-CRITIC review integration

hyperdoc

This page decomposes the LISP-CRITIC review integration plan into DITA-like task topic objects. Each task topic is related back to the concrete plan through a first-class plan-task relation.

Inspectable objects

  • integrate-lisp-critic-in-review-plan
  • inventory-fedwiki-lisp-critic-asset
  • relations for inventory-fedwiki-lisp-critic-asset
  • LISP-CRITIC review task decomposition

Task structure

Each task topic records an id, title, short description, context, prerequisites, steps, expected result, artifacts, evidence, and Goldberg questions. The task object is not the plan; the relation object is what says how a task belongs to a plan.

Tasks

  1. inventory-fedwiki-lisp-critic-asset: inventory the FedWiki asset source station and produce critic-source-manifest.
  2. define-critic-source-station-contract: define the source-station contract and produce fedwiki-critic-source.
  3. load-or-invoke-lisp-critic-without-vendoring: define the future invocation boundary without execution.
  4. normalize-lisp-critic-output-into-findings: plan the lisp-critic-finding schema.
  5. attach-critic-runs-to-review-contracts: bridge critic runs into existing review contracts.
  6. render-critic-contract-and-run-views: name the future inspector surfaces for source, rules, findings, raw output, and suppressions.
  7. expose-task-plan-relation-views: expose the task-to-plan relation surface.
  8. add-smoke-tests: validate the plan, relations, Goldberg coverage, and view construction.
  9. materialize-documentation-pages: document the plan and task decomposition in HyperDoc.

Relations to plans

Open any task topic and select the Relations to plans view. The view shows the related plan, relation type, ordinal, dependencies, produced artifacts, validated checks, and Goldberg questions answered.

Goldberg coverage

Open the concrete plan and select Goldberg coverage. The coverage view answers which task topics cover :where-is-it, :what-is-that, :what-is-needed, :why-happened, and :why-not-happened.

Boundary

These task topics are planning and reading objects. They do not load the LISP-CRITIC ASDF system, run the critic, call a FedWiki or DMX server, or mutate local source stations.
