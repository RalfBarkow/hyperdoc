SBCL (Steel Bank Common Lisp) is the Lisp implementation used by this repository for build, load, server runtime, and interactive inspection.

Operational role

  • Compiles and loads HyperDoc/HyperBook systems via ASDF.
  • Runs the web server and inspector event-handler threads.
  • Hosts Playground evaluation and debug surfaces.
