Definitive Common Lisp Books

hyperdoc

This page is a practical reading map for Common Lisp books. Here, definitive means books worth returning to at different stages of learning, not a claim that there is one final canon.

Good first books

  • Practical Common Lisp — Peter Seibel. Pragmatic, example-driven, and still one of the best first books for learning how to build real Common Lisp programs.
  • ANSI Common Lisp — Paul Graham. A tutorial plus reference-style introduction that is especially good for learning the core language carefully.
  • Common Lisp: A Gentle Introduction to Symbolic Computation — David S. Touretzky. Beginner-friendly and methodical, with a gentler slope than many Lisp books.
  • Land of Lisp — Conrad Barski. Playful and approachable, especially for readers who learn well through experiments and games.
  • Lisp, 3rd Edition — Patrick Henry Winston and Berthold Klaus Paul Horn. Better treated as older adjacent background than as a current Common Lisp-first recommendation.

Deepening Common Lisp technique

  • On Lisp — Paul Graham. Macro-heavy and advanced; best read after you are already comfortable writing ordinary Common Lisp.
  • Paradigms of Artificial Intelligence Programming — Peter Norvig. Substantial and demanding, but excellent for learning larger-scale Common Lisp problem-solving.

Object system and meta-level

  • Object-Oriented Programming in Common Lisp: A Programmer’s Guide to CLOS — Sonya E. Keene. Focused introduction to CLOS for programmers who want the object system explained directly.
  • The Art of the Metaobject Protocol — Gregor Kiczales, Jim des Rivières, and Daniel G. Bobrow. Advanced and MOP-focused; read it when you want to understand how the object system itself can be extended.

Historical and reference works

  • Common Lisp: The Language, 2nd Edition — Guy L. Steele Jr. Historically important and still useful as a language snapshot, but not the same thing as the finalized ANSI standard.
  • ANSI Common Lisp standard / Common Lisp HyperSpec. Authoritative reference material for the language, but not a tutorial.

Adjacent but not Common Lisp

  • Structure and Interpretation of Computer Programs. Influential for Lisp thinking, but it teaches Scheme rather than Common Lisp.
  • The Little Lisper / The Little Schemer. Valuable for recursive thinking and Lisp style, but also adjacent to Common Lisp rather than direct language guides.
