Task 2: Materialize the Drew McDermott topic layer in hyperdoc/topics.lisp

Context

The patch currently adds a proposed snippet file but does not merge the resulting topic factories into the durable topic-factory layer. That leaves topic links unresolved.

Prerequisites

  • You understand that topic pages in HyperBook topics are rebuilt from authored topic factories in hyperdoc/topics.lisp.
  • You can search existing topic titles before adding new ones.

Steps

  1. Open hyperdoc/drew-mcdermott-topics-snippet.lisp.
  2. For each proposed topic title, search hyperdoc/topics.lisp for an exact existing :title.
  3. If the title already exists, merge into the existing factory instead of adding a duplicate factory.
  4. If there is no exact title match, check aliases, near-duplicates, or broader existing topics before adding a new factory.
  5. Add only genuinely new topic factories to hyperdoc/topics.lisp.
  6. Do not leave the snippet file as the only place where the topic definitions exist.

Result

The Topics HyperBook can rebuild the Drew topic pages from durable factories instead of surfacing missing topic-page lookup issues.
