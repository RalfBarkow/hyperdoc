Verify HyperDoc locally before deployment

Run the minimum local checks before any remote activation.

Purpose

Fail fast locally if flake checks, runtime checks, or smoke checks are broken.

Prerequisites

  • Prepare hauptsache working tree for deployment has passed.

Context

Local verification gates deployment. Do not skip this and debug first on the server.

Steps

  1. Check local working tree: 
    git status --short
  2. Run flake checks: 
    nix flake check
  3. Run release smoke verification: 
    nix run .#release-smoke

Result

  • nix flake check exits 0.
  • nix run .#release-smoke exits 0 and prints the release verification success marker.
