Verify HyperDoc locally before deployment

Run local flake and release checks before any remote rebuild activation.

Inspectable objects

  • dreyeck local verification gate
  • dreyeck supported deployment model

Purpose

Catch build/runtime/doc consistency failures locally instead of discovering them after remote activation.

Prerequisites

  • Record dreyeck.ch generation before rebuild completed.

Context

Run all commands in this page on the local controller. Local verification gates deployment. Do not skip this and debug first on the server.

Steps

  1. Check local tree: 
    git status --short
  2. Run flake checks: 
    nix flake check
  3. Run release smoke: 
    nix run .#release-smoke

Result

  • nix flake check exits 0.
  • nix run .#release-smoke exits 0 with release verification success marker.
