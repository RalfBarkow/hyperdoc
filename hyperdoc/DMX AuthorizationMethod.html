DMX AuthorizationMethod

hyperdoc

DMX AuthorizationMethod is the DMX platform extension point for non-Basic Authorization schemes. It explains why bearer token mode in HyperDoc is an installation-dependent learning example rather than a universal DMX-core promise.

Platform contract

In dmx-platform, the interface systems.dmx.accesscontrol.AuthorizationMethod defines checkCredentials(Credentials cred). For non-Basic method names, DMX resolves an AuthorizationMethod implementation and asks it whether the supplied credentials are valid.

That means bearer-style support depends on one of two things:

  • a registered non-Basic AuthorizationMethod inside DMX itself
  • or an installation-specific proxy or gateway that turns a bearer token into a DMX-compatible backend session/header before the request reaches DMX

Why the crosswalk keeps this explicit

HyperDoc's repair console still normalizes bearer token as a valid operator input mode for learning and UI purposes, but the backend contract note must remain Installation-dependent. This page is the durable reason why.
