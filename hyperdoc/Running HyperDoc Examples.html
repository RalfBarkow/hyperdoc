Running HyperDoc Examples

hyperdoc

HyperDoc examples are not run by clicking on source code text. They are run by clicking the small ► button that HyperDoc inserts before a top-level defexample form.

The relevant mechanism is the method in hyperdoc-explorer/examples.lisp that extends html-inspector-views/standard:render-toplevel-cst for defexample.

What happens

  1. A HyperDoc page contains <source-of-function>...</source-of-function>.
  2. HyperDoc transcludes the source view for that function.
  3. If the transcluded top-level form is a defexample, HyperDoc adds a ► play button.
  4. Clicking ► runs the example and opens its result in a new pane.

Clicking the code itself does not run the example. The runnable affordance is the play button, not the source text.

Reloading the running image

If a page shows an example as undefined, the usual cause is that the running image was started before the new example function existed. In that case reload the system and reopen the page.

(progn (asdf:load-system :hyperdoc) nil)
