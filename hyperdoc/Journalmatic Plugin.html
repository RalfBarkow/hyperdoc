Journalmatic Plugin

~/workspace/wiki-plugin-journalmatic is a Federated Wiki plugin that exposes journal-checking and journal-repair operations through frame plugins.

It is useful for HyperDoc work because it already defines a compact tool vocabulary for exactly the kinds of failures we have been seeing in localhost pages.

What it contains

  • client/modules/journal-checker.js: checker logic
  • client/modules/revision.js: replay journal actions into page state
  • client/modules/chrono-fix.js: sort a journal by date
  • client/modules/compact-gentle.js: collapse short runs of edits
  • page surfaces such as Scan Site, Scan Page, Rectify Chronology, and Gentle Compactor

Why it matters here

Journalmatic is not a Lisp implementation, but it is still a valuable design reference. It shows that journal maintenance can be made operationally simple: scan, inspect findings, apply a bounded repair, and inspect the resulting page again.

Example vocabulary

  • creation: page creation is missing or not first
  • chronology: dates run backward
  • malformed: an action shape is wrong
  • revision: replay does not reconstruct the current page
  • huge and bloated: size heuristics for oversized journals

HyperDoc implication

HyperBook does not need to copy the frame-plugin UI. It does need the same operations in object form. The plugin therefore serves as a specification of useful journal tools, not as the final user interface.
