Programming style readability problem

hyperdoc

The base problem is not only whether a program runs. A program may pass the machine execution question and still fail the human reading question.

Execution problem

The execution problem asks: does the program run under the tested conditions? This is necessary, but it does not prove that the program is readable, criticizable, maintainable, or useful as a style example.

Readability problem

The readability problem asks whether a human reader can understand what the program means, criticize it, rewrite it, maintain it, and derive a transferable style rule from the rewrite.

Long-recognized problem

Kernighan/Plauger supply the base cycle for training readers on concrete code. Goldberg restates the same problem as a need for environment support in live, exploratory programming systems. Knuth's WEB keeps the program executable while arranging source material in reader order.
