HyperBook

A hyperbook is a collection of somehow related and usually interlinked hypertext pages in which each page has a unique identifier, which is often a page title. Some examples of HyperBooks are:

  • a HyperDoc
  • a Wikipedia edition
  • a Federated Wiki site
  • collections of linked notes: , Logseq, Denote, etc.
  • a Wiki attached to a Codebergrepository

Each of the hyperbook types mentioned above has its own conventions for establishing links between its pages, and none of them provides a bridge to other hyperbooks that would allow seamless browsing. This is what the HyperBook framework provides: conventions for linking between different hyperbooks, and a unified, extensible browser.

The conventions are very simple:

  1. Each hyperbook has a unique identifier.
  2. Each hyperbook page has an identifier that is unique inside the hyperbook.

Integration of a hyperbook type with the HyperBook browser requires a bit of code to be written.
